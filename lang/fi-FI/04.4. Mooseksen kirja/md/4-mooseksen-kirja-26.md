# 4. Mooseksen kirja Luku 26

## 4. Mooseksen kirja 26:1

Rutonkulun jälkeen Herra puhui Moosekselle ja pappi Aaronin pojalle Eleasarille sanoen:

## 4. Mooseksen kirja 26:2

"Toimittakaa koko Israelin kansan väestönlaskenta, kaksikymmenvuotiaista ja sitä vanhemmista, perhekunnittain, kaikkien, jotka pystyvät sotimaan Israelissa."

## 4. Mooseksen kirja 26:3

Niin Mooses ja pappi Eleasar puhuivat heille Mooabin arolla Jordanin luona vastapäätä Jerikoa sanoen:

## 4. Mooseksen kirja 26:4

"Toimittakaa väestönlaskenta kaksikymmenvuotiaista ja sitä vanhemmista, kuten Herra käski Moosesta." Nämä olivat ne israelilaiset, jotka lähtivät Egyptistä:

## 4. Mooseksen kirja 26:5

Ruubenin, Israelin esikoisen, jälkeläiset olivat: Hanochista, hanochilaisten perhe; Pallusta, pallulaisten perhe;

## 4. Mooseksen kirja 26:6

Hezronista, hezronilaisten perhe; Karmista, karmilaisten perhe.

## 4. Mooseksen kirja 26:7

Nämä olivat ruubenilaisten perheet, ja laskettuja oli 43 730.

## 4. Mooseksen kirja 26:8

Pallulla oli poika, Eliab.

## 4. Mooseksen kirja 26:9

Eliabin pojat olivat Nemuel, Datan ja Abiram. Nämä ovat samat Datan ja Abiram, jotka kutsuttiin seurakunnan eteen, jotka vastustivat Moosesta ja Aaronia Korahin seurassa, kun he vastustivat Herraa.

## 4. Mooseksen kirja 26:10

Maa avasi suunsa ja nielaisi heidät yhdessä Korahin kanssa, kun tuo joukko kuoli, kun tuli kulutti 250 miestä, ja heistä tuli varoitusmerkki.

## 4. Mooseksen kirja 26:11

Korahin suku ei kuitenkaan kuollut sukupuuttoon.

## 4. Mooseksen kirja 26:12

Simeonin jälkeläiset perhekunnittain olivat: Nemuelista, nemuelilaisten perhe; Jaminista, jaminilaisten perhe; Jakinista, jakinilaisten perhe;

## 4. Mooseksen kirja 26:13

Serahista, serahilaisten perhe; Saulista, saulilaisten perhe.

## 4. Mooseksen kirja 26:14

Nämä olivat simeonilaisten perheet, ja laskettuja oli 22 200.

## 4. Mooseksen kirja 26:15

Gadin jälkeläiset perhekunnittain olivat: Sefonista, sefonilaisten perhe; Haggista, haggilaisten perhe; Sunista, sunilaisten perhe;

## 4. Mooseksen kirja 26:16

Oznista, oznilaisten perhe; Eristä, erilaisten perhe;

## 4. Mooseksen kirja 26:17

Arodista, arodilaisten perhe; Arelista, arelilaisten perhe.

## 4. Mooseksen kirja 26:18

Nämä olivat Gadin poikien perheet, ja laskettuja oli 40 500.

## 4. Mooseksen kirja 26:19

Juudan pojat olivat Er ja Onan, mutta he kuolivat Kanaanin maassa.

## 4. Mooseksen kirja 26:20

Juudan jälkeläiset perhekunnittain olivat: Selasta, selanilaisten perhe; Peretsistä, peretsilaisten perhe; Serahista, serahilaisten perhe.

## 4. Mooseksen kirja 26:21

Peretsin jälkeläiset olivat: Hezronista, hezronilaisten perhe; Hamulista, hamulilaisten perhe.

## 4. Mooseksen kirja 26:22

Nämä olivat Juudan perheet, ja laskettuja oli 76 500.

## 4. Mooseksen kirja 26:23

Isaskarin jälkeläiset perhekunnittain olivat: Tolasta, tolaisten perhe; Puuvasta, puuvilaisten perhe;

## 4. Mooseksen kirja 26:24

Jasubista, jasubilaisten perhe; Simronista, simronilaisten perhe.

## 4. Mooseksen kirja 26:25

Nämä olivat Isaskarin perheet, ja laskettuja oli 64 300.

## 4. Mooseksen kirja 26:26

Sebulonin jälkeläiset perhekunnittain olivat: Seredistä, seredilaisten perhe; Elonista, elonilaisten perhe; Jahleelista, jahleelilaisten perhe.

## 4. Mooseksen kirja 26:27

Nämä olivat sebulonilaisten perheet, ja laskettuja oli 60 500.

## 4. Mooseksen kirja 26:28

Joosefin jälkeläiset perhekunnittain olivat Manasse ja Efraim.

## 4. Mooseksen kirja 26:29

Manassen jälkeläiset: Makirista, makirilaisten perhe; Makir oli Gileadin isä: Gileadista, gileadilaisten perhe.

## 4. Mooseksen kirja 26:30

Nämä olivat Gileadin jälkeläiset: Ieseristä, ieserilaisten perhe; Helekistä, helekilaisten perhe;

## 4. Mooseksen kirja 26:31

Asrielista, asrielilaisten perhe; Sikemistä, sikemilaisten perhe;

## 4. Mooseksen kirja 26:32

Semidasta, semidalaisten perhe; Heferistä, heferilaisten perhe.

## 4. Mooseksen kirja 26:33

Heferin poika Selofhadilla ei ollut poikia, vaan ainoastaan tyttäriä; ja Selofhadin tyttärien nimet olivat Mahla, Nooa, Hogla, Milka ja Tirsa.

## 4. Mooseksen kirja 26:34

Nämä olivat Manassen perheet, ja laskettuja oli 52 700.

## 4. Mooseksen kirja 26:35

Nämä olivat Efraimin jälkeläiset perhekunnittain: Sutelasta, sutelalaisten perhe; Bekkeristä, bekkerilaisten perhe; Tahanista, tahanilaisten perhe.

## 4. Mooseksen kirja 26:36

Nämä olivat Sutelan jälkeläiset: Eranista, eranilaisten perhe.

## 4. Mooseksen kirja 26:37

Nämä olivat Efraimin poikien perheet, ja laskettuja oli 32 500. Nämä olivat Joosefin jälkeläiset perhekunnittain.

## 4. Mooseksen kirja 26:38

Benjaminin jälkeläiset perhekunnittain olivat: Belasta, belalaisten perhe; Asbelista, asbelilaisten perhe; Ahiramista, ahiramilaisten perhe;

## 4. Mooseksen kirja 26:39

Sefufamista, sefufamilaisten perhe; Hufamista, hufamilaisten perhe.

## 4. Mooseksen kirja 26:40

Belan jälkeläiset olivat Ard ja Naaman: Ardista, ardilaisten perhe; Naamanista, naamanilaisten perhe.

## 4. Mooseksen kirja 26:41

Nämä olivat Benjaminin perheet, ja laskettuja oli 45 600.

## 4. Mooseksen kirja 26:42

Nämä olivat Danin jälkeläiset perhekunnittain: Suhamista, suhamilaisten perhe. Nämä olivat Danin perheet.

## 4. Mooseksen kirja 26:43

Kaikki suhamilaisten perheet, ja laskettuja oli 64 400.

## 4. Mooseksen kirja 26:44

Asserin jälkeläiset perhekunnittain olivat: Jimnasta, jimnalaisten perhe; Jisvistä, jisvilaisten perhe; Beriasta, berialaisten perhe.

## 4. Mooseksen kirja 26:45

Beriasta polveutuvat: Heberistä, heberilaisten perhe; Malkielista, malkielilaisten perhe.

## 4. Mooseksen kirja 26:46

Asserilla oli tytär nimeltä Serah.

## 4. Mooseksen kirja 26:47

Nämä olivat Asserin poikien perheet, ja laskettuja oli 53 400.

## 4. Mooseksen kirja 26:48

Naftalin jälkeläiset perhekunnittain olivat: Jahseelista, jahseelilaisten perhe; Gunista, gunilaisten perhe;

## 4. Mooseksen kirja 26:49

Jeeseristä, jeeserilaisten perhe; Sillemistä, sillemilaisten perhe.

## 4. Mooseksen kirja 26:50

Nämä olivat Naftalin perheet perhekunnittain, ja laskettuja oli 45 400.

## 4. Mooseksen kirja 26:51

Kaikkiaan israelilaisia laskettiin olevan 601 730.

## 4. Mooseksen kirja 26:52

Sitten Herra käski Moosesta,

## 4. Mooseksen kirja 26:53

"Maa jaettakoon heille perintöosaksi nimien lukumäärän mukaan.

## 4. Mooseksen kirja 26:54

Suuremmalle ryhmälle annettakoon suurempi perintöosa, ja pienemmälle ryhmälle pienempi; kukin saakoon perintöosansa luetteloitujen lukumäärän mukaan.

## 4. Mooseksen kirja 26:55

Huolehdi, että maa jaetaan arpomalla. Mitä kukin ryhmä perii, määräytyy heidän esi-isiensä heimojen nimien mukaan.

## 4. Mooseksen kirja 26:56

Perintöosa jaettakoon arpomalla suurempien ja pienempien ryhmien kesken.

## 4. Mooseksen kirja 26:57

Nämä olivat leeviläiset, jotka laskettiin perhekunnittain: Gersonista, gersonilaisten perhe; Kehatista, kehatilaisten perhe; Merarista, merarilaisten perhe.

## 4. Mooseksen kirja 26:58

Nämä olivat myös leeviläisten perheet: libnilaisten perhe, hebronilaisten perhe, mahlilaisten perhe, musilaisten perhe ja korahilaisten perhe. Kehat oli Amramin isä.

## 4. Mooseksen kirja 26:59

Amramin vaimon nimi oli Jookebed, Leevin tytär, joka syntyi leeviläisille Egyptissä. Amramille hän synnytti Aaronin, Mooseksen ja heidän sisarensa Mirjamin.

## 4. Mooseksen kirja 26:60

Aaronin pojat olivat Naadab ja Abihu, Eleasar ja Iitamar.

## 4. Mooseksen kirja 26:61

Mutta Naadab ja Abihu kuolivat, kun he toivat luvattoman tulen Herran eteen.

## 4. Mooseksen kirja 26:62

Kaikkiaan miespuolisia leeviläisiä kuukauden ikäisistä ja sitä vanhemmista oli 23 000. Heitä ei laskettu muiden israelilaisten joukkoon, koska he eivät saaneet perintöosaa heidän keskuudessaan.

## 4. Mooseksen kirja 26:63

Nämä ovat ne, jotka Mooses ja pappi Eleasar luettelivat, kun he laskivat israelilaiset Mooabin arolla Jordanin luona vastapäätä Jerikoa.

## 4. Mooseksen kirja 26:64

Näiden joukossa ei ollut yhtäkään niistä, jotka Mooses ja pappi Aaron laskivat, kun he laskivat israelilaiset Siinain erämaassa.

## 4. Mooseksen kirja 26:65

Sillä Herra oli sanonut heistä: "He kuolevat varmasti erämaassa." Heistä ei jäänyt jäljelle yhtäkään, paitsi Kaaleb, Jefunnen poika, ja Joosua, Nuunin poika.
