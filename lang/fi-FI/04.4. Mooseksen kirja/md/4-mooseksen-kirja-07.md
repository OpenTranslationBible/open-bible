# 4. Mooseksen kirja Luku 7

## 4. Mooseksen kirja 7:1

Sinä päivänä, jona Mooses sai valmiiksi ilmestysmajan pystyttämisen, hän voiteli ja pyhitti sen kaikkine kalustoineen, ja alttarin kaikkine välineineen; hän voiteli ja pyhitti nekin.

## 4. Mooseksen kirja 7:2

Sitten Israelin johtajat, isiensä perheiden päämiehet, jotka olivat heimopäälliköitä ja valvoivat laskettuja, toivat lahjoja.

## 4. Mooseksen kirja 7:3

He toivat lahjansa Herran eteen: kuusi peitettyä vaunua ja kaksitoista härkää—yksi härkä jokaiselta johtajalta ja vaunu kahdelta johtajalta. He esittivät nämä ilmestysmajan edessä.

## 4. Mooseksen kirja 7:4

Sitten Herra puhui Moosekselle sanoen,

## 4. Mooseksen kirja 7:5

"Ota nämä heiltä, että niitä voidaan käyttää ilmestysmajan palveluksessa. Jaa ne leeviläisille kunkin miehen palveluksen mukaan."

## 4. Mooseksen kirja 7:6

Niin Mooses otti vaunut ja härät ja jakoi ne leeviläisille.

## 4. Mooseksen kirja 7:7

Hän antoi kaksi vaunua ja neljä härkää Gersonin pojille heidän palveluksensa mukaan,

## 4. Mooseksen kirja 7:8

ja hän antoi neljä vaunua ja kahdeksan härkää Merarin pojille heidän palveluksensa mukaan, pappi Aaronin pojan Iitamarin valvonnassa.

## 4. Mooseksen kirja 7:9

Mutta hän ei antanut mitään Kehatin pojille, koska he vastasivat pyhistä esineistä, jotka he kantoivat olkapäillään.

## 4. Mooseksen kirja 7:10

Johtajat toivat lahjansa alttarin vihkimiseen, kun se voideltiin, esittäen ne alttarin edessä.

## 4. Mooseksen kirja 7:11

## 4. Mooseksen kirja 7:14

## 4. Mooseksen kirja 7:17

Nämä olivat israelilaisten johtajien lahjat alttarin vihkimiseen, kun se voideltiin: kaksitoista hopeavatia, kaksitoista hopeakulhoa ja kaksitoista kultaista maljaa.

## 4. Mooseksen kirja 7:85

Jokainen hopeavati painoi 130 sekeliä, ja jokainen kulho seitsemänkymmentä sekeliä. Yhteensä näiden välineiden hopea painoi 2 400 sekeliä pyhäkkösekelin mukaan.

## 4. Mooseksen kirja 7:86

## 4. Mooseksen kirja 7:87

## 4. Mooseksen kirja 7:88

Yhteysuhriksi tuli yhteensä kaksikymmentäneljä härkää, kuusikymmentä pässiä, kuusikymmentä urosvuohipukkia ja kuusikymmentä vuoden vanhaa uroskaritsaa. Nämä olivat alttarin vihkimiseen tuodut lahjat sen voitelun jälkeen.

## 4. Mooseksen kirja 7:89

Kun Mooses meni ilmestysmajaan puhumaan Herralle, hän kuuli äänen puhuvan hänelle armoistuimen yläpuolelta todistuksen arkin päältä, kahden kerubin välistä; näin Herra puhui hänelle.
