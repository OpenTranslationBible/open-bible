# 4. Mooseksen kirja Luku 3

## 4. Mooseksen kirja 3:1

Nämä ovat Aaronin ja Mooseksen perheen kirjat siihen aikaan, kun Herra puhui Moosekselle Siinain vuorella.

## 4. Mooseksen kirja 3:2

Aaronin pojat olivat Nadab, esikoinen, Abihu, Eleasar ja Itamar.

## 4. Mooseksen kirja 3:3

Nämä olivat Aaronin poikien nimet, voidellut papit, jotka oli asetettu palvelemaan pappeina.

## 4. Mooseksen kirja 3:4

Kuitenkin Nadab ja Abihu kuolivat Herran edessä, kun he toivat luvattoman tulen Hänen eteensä Siinain erämaassa; eikä heillä ollut poikia. Niin Eleasar ja Itamar palvelivat pappeina isänsä Aaronin elinaikana.

## 4. Mooseksen kirja 3:5

Herra puhui sitten Moosekselle sanoen,

## 4. Mooseksen kirja 3:6

"Tuo Leevin heimo esiin ja aseta heidät Aaronin, papin, eteen, että he auttaisivat häntä.

## 4. Mooseksen kirja 3:7

Heidän tulee suorittaa tehtäviä hänen ja koko seurakunnan puolesta ilmestysmajassa, tekemällä ilmestysmajan työtä.

## 4. Mooseksen kirja 3:8

He ovat vastuussa kaikista ilmestysmajan kalusteista, täyttäen israelilaisten velvollisuudet hoitamalla ilmestysmajan työtä.

## 4. Mooseksen kirja 3:9

Anna leeviläiset Aaronille ja hänen pojilleen; heidät on yksinomaan annettu hänelle israelilaisten joukosta.

## 4. Mooseksen kirja 3:10

Aseta Aaron ja hänen poikansa palvelemaan pappeina; mutta maallikko, joka lähestyy pyhäkköä, on surmattava."

## 4. Mooseksen kirja 3:11

Herra puhui jälleen Moosekselle sanoen,

## 4. Mooseksen kirja 3:12

"Katso, minä olen ottanut leeviläiset israelilaisten joukosta jokaisen esikoisen, kohdun esikoisen, sijaan Israelin pojista. Leeviläiset ovat minun,

## 4. Mooseksen kirja 3:13

sillä kaikki esikoiset ovat minun. Sinä päivänä, kun minä löin kaikki esikoiset Egyptin maassa, pyhitin itselleni kaikki esikoiset Israelissa, sekä ihmiset että eläimet. He ovat minun; minä olen Herra."

## 4. Mooseksen kirja 3:14

Herra puhui Moosekselle Siinain erämaassa,

## 4. Mooseksen kirja 3:15

"Laske Leevin pojat heidän perheidensä ja sukujensa mukaan; jokainen miespuolinen kuukauden ikäisestä ylöspäin sinun tulee laskea."

## 4. Mooseksen kirja 3:16

Niin Mooses laski heidät Herran sanan mukaan, aivan kuten häntä oli käsketty.

## 4. Mooseksen kirja 3:17

Nämä ovat Leevin pojat heidän nimensä mukaan: Gerson, Kehat ja Merari.

## 4. Mooseksen kirja 3:18

Nämä ovat Gersonin pojat heidän perheidensä mukaan: Libni ja Simei.

## 4. Mooseksen kirja 3:19

Kehatin jälkeläiset heidän perheidensä mukaan olivat Amram, Jishar, Hebron ja Ussiel.

## 4. Mooseksen kirja 3:20

Merarin pojat heidän perheidensä mukaan olivat Mahli ja Muusi. Nämä ovat leeviläisten perheet heidän isiensä sukujen mukaan.

## 4. Mooseksen kirja 3:21

Gersonista tulivat Libniläisten ja Simeiläisten perheet; nämä olivat Gersonilaisten perheet.

## 4. Mooseksen kirja 3:22

Heidän laskettujen miestensä lukumäärä, jokainen miespuolinen kuukauden ikäisestä ylöspäin, oli 7,500.

## 4. Mooseksen kirja 3:23

Gersonilaisten perheiden tuli leiriytyä länteen, ilmestysmajan taakse.

## 4. Mooseksen kirja 3:24

Gersonilaisten isien sukujen päämies oli Eljasaf, Laelin poika.

## 4. Mooseksen kirja 3:25

Gersonin poikien tehtäviin ilmestysmajassa kuuluivat ilmestysmaja ja teltta, sen peite ja esirippu ilmestysmajan sisäänkäynnille,

## 4. Mooseksen kirja 3:26

ja esipihan verhot, esipihan sisäänkäynnin esirippu, joka ympäröi ilmestysmajaa ja alttaria, ja sen köydet, kaiken palveluksen mukaan, joka koskee niitä.

## 4. Mooseksen kirja 3:27

Kehatista tulivat Amramilaisten, Jisharilaisten, Hebronilaisten ja Ussielilaisten perheet; nämä olivat Kehatilaisten perheet.

## 4. Mooseksen kirja 3:28

Jokaisen miespuolisen kuukauden ikäisestä ylöspäin laskettuna heitä oli 8,600, vastuussa pyhäkön tehtävistä.

## 4. Mooseksen kirja 3:29

Kehatin jälkeläisten perheiden tuli leiriytyä ilmestysmajan eteläpuolelle.

## 4. Mooseksen kirja 3:30

Kehatilaisten perheiden isien sukujen päämies oli Elisafan, Ussielin poika.

## 4. Mooseksen kirja 3:31

Heidän tehtäviinsä kuuluivat arkki, pöytä, lampunjalka, alttarit, pyhäkön astiat, joilla he palvelivat, esirippu ja kaikki palvelus, joka koskee niitä.

## 4. Mooseksen kirja 3:32

Eleasar, Aaronin poika, pappi, oli Leevin päämiesten johtaja, valvoen niitä, jotka suorittivat pyhäkön tehtäviä.

## 4. Mooseksen kirja 3:33

Merarista tulivat Mahlilaisten ja Muusilaisten perheet; nämä olivat Merarin perheet.

## 4. Mooseksen kirja 3:34

Heidän laskettujen miestensä lukumäärä, jokainen miespuolinen kuukauden ikäisestä ylöspäin, oli 6,200.

## 4. Mooseksen kirja 3:35

Merarin perheiden isien sukujen päämies oli Suriel, Abihailin poika. Heidän tuli leiriytyä ilmestysmajan pohjoispuolelle.

## 4. Mooseksen kirja 3:36

Merarin poikien tehtäviin kuuluivat ilmestysmajan kehys, sen poikkipuut, pilarit, jalustat, kaikki sen varusteet ja kaikki palvelus, joka koskee niitä,

## 4. Mooseksen kirja 3:37

ja esipihan pilarit niiden jalustoineen, niiden vaarnat ja köydet.

## 4. Mooseksen kirja 3:38

Ne, joiden tuli leiriytyä ilmestysmajan eteen itään, ilmestysmajan eteen auringonnousuun päin, olivat Mooses ja Aaron ja hänen poikansa, suorittaen pyhäkön tehtäviä Israelin poikien velvollisuudeksi; mutta maallikko, joka lähestyi, oli surmattava.

## 4. Mooseksen kirja 3:39

Kaikki leeviläisten lasketut miehet, jotka Mooses ja Aaron laskivat Herran käskystä heidän perheidensä mukaan, jokainen miespuolinen kuukauden ikäisestä ylöspäin, olivat 22,000.

## 4. Mooseksen kirja 3:40

Sitten Herra käski Moosesta: "Laske jokainen esikoispoika Israelin pojista kuukauden ikäisestä ylöspäin ja tee luettelo heidän nimistään.

## 4. Mooseksen kirja 3:41

Ja sinun tulee ottaa leeviläiset minulle—minä olen Herra—vaihdossa kaikkien esikoisten sijasta Israelin pojista; ja leeviläisten karja vaihdossa kaikkien esikoisten sijasta Israelin poikien karjasta."

## 4. Mooseksen kirja 3:42

Niin Mooses laski kaikki esikoiset Israelin pojista, aivan kuten Herra oli häntä käskenyt.

## 4. Mooseksen kirja 3:43

Ja kaikki esikoispojat, nimien lukumäärän mukaan kuukauden ikäisestä ylöspäin, olivat 22,273.

## 4. Mooseksen kirja 3:44

Herra puhui sitten Moosekselle sanoen,

## 4. Mooseksen kirja 3:45

"Ota leeviläiset vaihdossa kaikkien esikoisten sijasta Israelin pojista, ja leeviläisten karja heidän karjansa sijasta. Ja leeviläiset ovat minun; minä olen Herra.

## 4. Mooseksen kirja 3:46

Ja lunastushintana 273:lle Israelin poikien esikoisista, jotka ylittävät leeviläisten lukumäärän,

## 4. Mooseksen kirja 3:47

sinun tulee kerätä viisi sekeliä jokaiselta; sinun tulee ottaa ne pyhäkön sekeliä kohti (sekeli on kaksikymmentä geraa),

## 4. Mooseksen kirja 3:48

ja sinun tulee antaa raha, niiden lunastushinta, jotka ovat ylittäviä heidän joukossaan, Aaronille ja hänen pojilleen."

## 4. Mooseksen kirja 3:49

Niin Mooses keräsi lunastusrahan niiltä, jotka ylittivät leeviläisten lunastettujen lukumäärän;

## 4. Mooseksen kirja 3:50

Israelilaisten esikoisista hän keräsi rahaa pyhäkön sekeliä kohti, 1,365.

## 4. Mooseksen kirja 3:51

Sitten Mooses antoi lunastusrahan Aaronille ja hänen pojilleen, Herran käskystä, aivan kuten Herra oli Moosesta käskenyt.
