# 4. Mooseksen kirja Luku 28

## 4. Mooseksen kirja 28:1

Herra puhui Moosekselle sanoen nämä sanat:

## 4. Mooseksen kirja 28:2

"Käske israelilaisia ja sano heille: 'Olkaa tarkkoja tuodessanne minulle uhrini, ruokauhrini tulena, miellyttävänä tuoksuna minulle, määräaikoinaan.'

## 4. Mooseksen kirja 28:3

Sano heille: 'Tämä on tulen uhri, jonka teidän tulee tuoda Herralle: kaksi virheetöntä vuoden vanhaa urospuolista karitsaa, jokapäiväisenä jatkuvana polttouhrina.

## 4. Mooseksen kirja 28:4

Toimittakaa yksi karitsa aamulla ja toinen iltahämärässä;

## 4. Mooseksen kirja 28:5

yhdessä kymmenyksen eefa-mittaa parhainta jauhoa sekoitettuna neljännes hin-mittaa puhdasta öljyä viljauhriksi.

## 4. Mooseksen kirja 28:6

Tämä on jatkuva polttouhri, joka on säädetty Siinain vuorella miellyttävänä tuoksuna, tulen uhrina Herralle.

## 4. Mooseksen kirja 28:7

Mukana oleva juomauhri on neljännes hin-mittaa väkevää juomaa kutakin karitsaa kohti. Kaada juomauhri Herralle pyhäkössä.

## 4. Mooseksen kirja 28:8

Toimittakaa toinen karitsa iltahämärässä samanlaisen viljauhrin ja juomauhrin kanssa kuin aamulla, tulen uhrina, rauhoittavana tuoksuna Herralle.

## 4. Mooseksen kirja 28:9

"'Sapatin päivänä toimittakaa kaksi virheetöntä vuoden vanhaa urospuolista karitsaa, kaksi kymmenystä eefa-mittaa parhainta jauhoa sekoitettuna öljyyn viljauhriksi, ja sen juomauhri.

## 4. Mooseksen kirja 28:10

Tämä on polttouhri kutakin sapattia varten, säännöllisen polttouhrin ja sen juomauhrin lisäksi.

## 4. Mooseksen kirja 28:11

"'Jokaisen kuukauden alussa toimittakaa Herralle polttouhri: kaksi nuorta sonnia, yksi pässi ja seitsemän virheetöntä vuoden vanhaa urospuolista karitsaa.

## 4. Mooseksen kirja 28:12

Kutakin sonnia kohti olkoon viljauhrina kolme kymmenystä eefa-mittaa parhainta jauhoa sekoitettuna öljyyn; pässiä kohti kaksi kymmenystä eefa-mittaa parhainta jauhoa sekoitettuna öljyyn;

## 4. Mooseksen kirja 28:13

ja kutakin karitsaa kohti kymmenys eefa-mittaa parhainta jauhoa sekoitettuna öljyyn. Tämä on polttouhri, miellyttävä tuoksu, tulen uhri Herralle.

## 4. Mooseksen kirja 28:14

Kutakin sonnia kohti olkoon juomauhri puoli hin-mittaa viiniä; pässiä kohti kolmannes hin-mittaa; ja kutakin karitsaa kohti neljännes hin-mittaa. Tämä on kuukausittainen polttouhri, joka on toimitettava jokaisen uudenkuun aikana vuoden mittaan.

## 4. Mooseksen kirja 28:15

Säännöllisen polttouhrin ja sen juomauhrin lisäksi toimittakaa yksi urospuolinen vuohi syntiuhrina Herralle.

## 4. Mooseksen kirja 28:16

"'Herran pääsiäinen on pidettävä ensimmäisen kuukauden neljäntenätoista päivänä.

## 4. Mooseksen kirja 28:17

Tämän kuukauden viidestoista päivänä on pidettävä juhla; seitsemän päivän ajan syökää happamatonta leipää.

## 4. Mooseksen kirja 28:18

Ensimmäisenä päivänä pitäkää pyhä kokous älkääkä tehkö mitään raskasta työtä.

## 4. Mooseksen kirja 28:19

Toimittakaa Herralle tulen uhri, polttouhri: kaksi nuorta sonnia, yksi pässi ja seitsemän virheetöntä vuoden vanhaa urospuolista karitsaa.

## 4. Mooseksen kirja 28:20

Kutakin sonnia kohti valmistakaa viljauhrina kolme kymmenystä eefa-mittaa parhainta jauhoa sekoitettuna öljyyn; pässiä kohti kaksi kymmenystä;

## 4. Mooseksen kirja 28:21

ja kutakin seitsemää karitsaa kohti yksi kymmenys.

## 4. Mooseksen kirja 28:22

Toimittakaa yksi urospuolinen vuohi syntiuhrina sovituksen saamiseksi teille.

## 4. Mooseksen kirja 28:23

Toimittakaa nämä uhrit säännöllisen aamu polttouhrin lisäksi.

## 4. Mooseksen kirja 28:24

Tällä tavalla toimittakaa ruokauhri joka päivä seitsemän päivän ajan miellyttävänä tuoksuna Herralle; se on toimitettava säännöllisen polttouhrin ja sen juomauhrin lisäksi.

## 4. Mooseksen kirja 28:25

Seitsemäntenä päivänä pitäkää pyhä kokous älkääkä tehkö mitään raskasta työtä.

## 4. Mooseksen kirja 28:26

"'Ensimäisten hedelmien päivänä, kun toimitatte Herralle uuden viljan uhrin Viikkojuhlan aikana, pitäkää pyhä kokous älkääkä tehkö mitään raskasta työtä.

## 4. Mooseksen kirja 28:27

Toimittakaa polttouhri: kaksi nuorta sonnia, yksi pässi ja seitsemän virheetöntä vuoden vanhaa urospuolista karitsaa miellyttävänä tuoksuna Herralle.

## 4. Mooseksen kirja 28:28

Kutakin sonnia kohti olkoon viljauhrina kolme kymmenystä eefa-mittaa parhainta jauhoa sekoitettuna öljyyn; pässiä kohti kaksi kymmenystä;

## 4. Mooseksen kirja 28:29

ja kutakin seitsemää karitsaa kohti yksi kymmenys.

## 4. Mooseksen kirja 28:30

Toimittakaa yksi urospuolinen vuohi sovituksen saamiseksi teille.

## 4. Mooseksen kirja 28:31

Toimittakaa nämä yhdessä niiden juomauhrien kanssa, säännöllisen polttouhrin ja sen viljauhrin lisäksi. Varmistakaa, että eläimet ovat virheettömiä.
