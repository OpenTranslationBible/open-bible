# 4. Mooseksen kirja Luku 17

## 4. Mooseksen kirja 17:1

Herra puhui Moosekselle sanoen:

## 4. Mooseksen kirja 17:2

"Puhu israelilaisille ja kerää heiltä sauva jokaista sukukuntaa kohti: kaksitoista sauvaa, yksi jokaiselta heidän sukukuntiensa johtajalta. Kirjoita kunkin miehen nimi hänen sauvaansa.

## 4. Mooseksen kirja 17:3

Leevin sauvaan kirjoita Aaronin nimi, sillä jokaisella sukukunnan johtajalla tulee olla yksi sauva.

## 4. Mooseksen kirja 17:4

Aseta ne ilmestysmajaan todistuksen eteen, jossa minä kohtaan sinut.

## 4. Mooseksen kirja 17:5

Sen miehen sauva, jonka minä valitsen, versoo, ja tämä lopettaa israelilaisten nurinan teitä vastaan."

## 4. Mooseksen kirja 17:6

Mooses puhui israelilaisille, ja heidän johtajansa antoivat hänelle kaksitoista sauvaa, yhden jokaiselta heidän sukukuntiensa johtajalta, mukaan lukien Aaronin sauva.

## 4. Mooseksen kirja 17:7

Mooses asetti sauvat Herran eteen todistuksen majaan.

## 4. Mooseksen kirja 17:8

Seuraavana päivänä Mooses meni majaan ja näki, että Aaronin sauva, joka edusti Leevin sukua, oli versonut, kukkinut ja tuottanut manteleita.

## 4. Mooseksen kirja 17:9

Mooses toi sitten kaikki sauvat Herran edestä kaikille israelilaisille. He tarkastelivat niitä, ja jokainen johtaja otti takaisin oman sauvansa.

## 4. Mooseksen kirja 17:10

Herra käski Moosesta: "Palauta Aaronin sauva todistuksen eteen, säilytettäväksi merkkinä kapinallisia vastaan, jotta heidän nurinansa minua vastaan lakkaisi eikä he kuolisi."

## 4. Mooseksen kirja 17:11

Mooses noudatti Herran ohjeita tarkasti.

## 4. Mooseksen kirja 17:12

Israelilaiset sanoivat Moosekselle: "Me olemme tuhoon tuomittuja! Me olemme menehtymässä, me kaikki olemme menehtymässä!

## 4. Mooseksen kirja 17:13

Jokainen, joka lähestyy Herran pyhäkköä, kuolee. Olemmeko me kaikki täysin menehtymässä?"
