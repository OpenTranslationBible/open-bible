# 4. Mooseksen kirja Luku 22

## 4. Mooseksen kirja 22:1
Israelilaiset matkustivat Mooabin tasangoille ja leiriytyivät Jordanin varrelle, Jerikoa vastapäätä.

## 4. Mooseksen kirja 22:2
Balak, Sipporin poika, näki kaiken, mitä Israel oli tehnyt amorilaisille.

## 4. Mooseksen kirja 22:3
Moab pelkäsi suuresti kansaa, koska heitä oli paljon; Moab oli kauhuissaan israelilaisten vuoksi.

## 4. Mooseksen kirja 22:4
Moabilaiset sanoivat Midianin vanhimmille: "Tämä joukko kuluttaa kaiken ympäriltämme, kuten härkä syö pellon ruohon." Balak, Sipporin poika, oli tuohon aikaan Mooabin kuningas.

## 4. Mooseksen kirja 22:5
Hän lähetti sanansaattajia kutsumaan Bileamia, Beorin poikaa, joka oli Petorissa lähellä Eufratia, kotimaassaan. Balak sanoi: "Kansa on tullut Egyptistä; he peittävät maan pinnan ja ovat asettuneet viereeni.

## 4. Mooseksen kirja 22:6
Tule, kiroa tämä kansa puolestani, sillä he ovat liian voimakkaita minulle. Ehkä pystyn voittamaan heidät ja karkottamaan heidät maasta. Tiedän, että kenet sinä siunaat, se on siunattu, ja kenet sinä kiroat, se on kirottu."

## 4. Mooseksen kirja 22:7
Mooabin ja Midianin vanhimmat lähtivät, mukanaan palkkio ennustamisesta. Kun he saapuivat Bileamin luo, he kertoivat hänelle Balakin viestin.

## 4. Mooseksen kirja 22:8
Bileam sanoi heille: "Viettäkää yö täällä, ja minä tuon teille vastauksen, jonka Herra antaa minulle." Niin moabilaisten johtajat jäivät hänen luokseen.

## 4. Mooseksen kirja 22:9
Herra lähestyi Bileamia ja kysyi: "Keitä nämä miehet ovat, jotka ovat kanssasi?"

## 4. Mooseksen kirja 22:10
Bileam vastasi Jumalalle: "Balak, Sipporin poika, Mooabin kuningas, lähetti minulle tämän viestin:

## 4. Mooseksen kirja 22:11
'Kansa on tullut Egyptistä ja peittää maan pinnan. Tule nyt, kiroa heidät puolestani; ehkä pystyn taistelemaan heitä vastaan ja karkottamaan heidät.'"

## 4. Mooseksen kirja 22:12
Mutta Jumala sanoi Bileamille: "Älä mene heidän kanssaan. Sinun ei tule kirota kansaa, sillä he ovat siunattuja."

## 4. Mooseksen kirja 22:13
Bileam nousi aamulla ja kertoi Balakin virkamiehille: "Palatkaa omaan maahanne, sillä Herra on kieltäytynyt antamasta minun mennä kanssanne."

## 4. Mooseksen kirja 22:14
Moabilaiset virkamiehet palasivat Balakin luo ja kertoivat: "Bileam kieltäytyi tulemasta kanssamme."

## 4. Mooseksen kirja 22:15
Balak lähetti toisia virkamiehiä, lukuisampia ja arvokkaampia kuin ensimmäiset.

## 4. Mooseksen kirja 22:16
He tulivat Bileamin luo ja sanoivat: "Tämä on Balakin, Sipporin pojan, sanoma: Älä anna minkään estää sinua tulemasta luokseni,

## 4. Mooseksen kirja 22:17
sillä minä palkitsen sinut runsaasti ja teen mitä tahansa pyydät. Tule, kiroa tämä kansa puolestani."

## 4. Mooseksen kirja 22:18
Bileam vastasi heille: "Vaikka Balak antaisi minulle palatsinsa täynnä hopeaa ja kultaa, en voisi tehdä mitään suurta tai pientä Herran, Jumalani, käskyn ulkopuolella.

## 4. Mooseksen kirja 22:19
Nyt, olkaa hyvä ja jääkää tänne myös täksi yöksi, jotta voin saada tietää, mitä muuta Herra minulle kertoo."

## 4. Mooseksen kirja 22:20
Sinä yönä Jumala tuli Bileamin luo ja sanoi: "Koska nämä miehet ovat tulleet kutsumaan sinua, mene heidän kanssaan, mutta tee vain se, mitä minä käsken sinun tehdä."

## 4. Mooseksen kirja 22:21
Bileam nousi varhain, valmisti aasinsa ja lähti moabilaisten virkamiesten kanssa.

## 4. Mooseksen kirja 22:22
Mutta Jumala vihastui, kun hän meni, ja Herran enkeli asettui tielle vastustamaan häntä. Bileam ratsasti aasillaan, ja hänen kaksi palvelijaansa olivat hänen kanssaan.

## 4. Mooseksen kirja 22:23
Kun aasi näki Herran enkelin seisovan tiellä miekka kädessään, se poikkesi tieltä pellolle. Bileam löi sitä saadakseen sen takaisin tielle.

## 4. Mooseksen kirja 22:24
Herran enkeli asettui sitten kapealle polulle viinitarhojen välissä, molemmin puolin muureja.

## 4. Mooseksen kirja 22:25
Kun aasi näki Herran enkelin, se painautui seinää vasten, murskaten Bileamin jalan sitä vasten. Niin hän löi aasia uudelleen.

## 4. Mooseksen kirja 22:26
Herran enkeli siirtyi eteenpäin ja asettui kapeaan paikkaan, jossa ei ollut tilaa kääntyä, ei oikealle eikä vasemmalle.

## 4. Mooseksen kirja 22:27
Nähdessään Herran enkelin aasi laskeutui Bileamin alle, mikä sai hänet vihastumaan ja lyömään sitä sauvalla.

## 4. Mooseksen kirja 22:28
Silloin Herra antoi aasille kyvyn puhua, ja se sanoi Bileamille: "Mitä olen tehnyt sinulle, että olet lyönyt minua nämä kolme kertaa?"

## 4. Mooseksen kirja 22:29
Bileam vastasi aasille: "Olet nolannut minut! Jos minulla vain olisi miekka kädessäni, olisin tappanut sinut nyt."

## 4. Mooseksen kirja 22:30
Aasi sanoi Bileamille: "Enkö ole sinun oma aasisi, jolla olet ratsastanut koko elämäsi tähän päivään asti? Olenko koskaan ollut tottunut tekemään näin sinulle?" "En", hän vastasi.

## 4. Mooseksen kirja 22:31
Silloin Herra antoi Bileamin nähdä selvästi, ja hän havaitsi Herran enkelin seisovan tiellä miekka paljastettuna. Niin hän kumartui alas ja heittäytyi kasvoilleen.

## 4. Mooseksen kirja 22:32
Herran enkeli kysyi häneltä: "Miksi olet lyönyt aasiaasi nämä kolme kertaa? Olen tullut tänne vastustamaan sinua, koska tiesi on uhkarohkea minun edessäni.

## 4. Mooseksen kirja 22:33
Aasi näki minut ja poikkesi tieltä nämä kolme kertaa. Jos se ei olisi poikennut, olisin varmasti ottanut henkesi nyt, mutta olisin säästänyt sen."

## 4. Mooseksen kirja 22:34
Bileam sanoi Herran enkelille: "Olen tehnyt syntiä. En tajunnut, että seisot tiellä vastustamassa minua. Jos olet tyytymätön, palaan takaisin."

## 4. Mooseksen kirja 22:35
Herran enkeli sanoi Bileamille: "Mene miesten kanssa, mutta puhu vain se, mitä minä käsken sinun puhua." Niin Bileam jatkoi Balakin virkamiesten kanssa.

## 4. Mooseksen kirja 22:36
Kuultuaan Bileamin lähestymisestä Balak meni häntä vastaan Mooabin kaupunkiin Arnonin rajalla, alueensa reunalla.

## 4. Mooseksen kirja 22:37
Balak sanoi Bileamille: "Enkö lähettänyt sinulle kiireellistä kutsua? Miksi et tullut luokseni? Olenko todella kykenemätön palkitsemaan sinua?"

## 4. Mooseksen kirja 22:38
Bileam vastasi: "No, olen tullut luoksesi nyt. Mutta voinko sanoa mitä tahansa? Minun on puhuttava vain se, mitä Jumala panee suuhuni."

## 4. Mooseksen kirja 22:39
Bileam seurasi sitten Balakia Kirjat-Husotiin.

## 4. Mooseksen kirja 22:40
Balak uhrasi karjaa ja lampaita ja jakoi niitä Bileamille ja hänen mukanaan oleville virkamiehille.

## 4. Mooseksen kirja 22:41
Seuraavana aamuna Balak vei Bileamin Baalin uhrikukkuloille, ja sieltä hän saattoi nähdä osan israelilaisten leiristä.
