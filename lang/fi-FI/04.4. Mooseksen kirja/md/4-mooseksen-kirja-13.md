# 4. Mooseksen kirja Luku 13

## 4. Mooseksen kirja 13:1

Sitten Herra puhui Moosekselle ja sanoi:

## 4. Mooseksen kirja 13:2

"Lähetä miehiä tutkimaan Kanaanin maata, jonka minä annan israelilaisille. Lähetä yksi mies kustakin heidän isäinsä sukukunnasta, jokainen heistä on johtaja."

## 4. Mooseksen kirja 13:3

Niinpä Herran käskystä Mooses lähetti heidät Paran autiomaasta, kaikki he olivat israelilaisten johtajia.

## 4. Mooseksen kirja 13:4

Tässä ovat heidän nimensä: Ruubenin sukukunnasta, Sammua, Sakkurin poika;

## 4. Mooseksen kirja 13:5

Simeonin sukukunnasta, Safat, Horin poika;

## 4. Mooseksen kirja 13:6

Juudan sukukunnasta, Kaleb, Jefunnen poika;

## 4. Mooseksen kirja 13:7

Isaskarin sukukunnasta, Jigal, Joosefin poika;

## 4. Mooseksen kirja 13:8

Efraimin sukukunnasta, Hoosea, Nuunin poika;

## 4. Mooseksen kirja 13:9

Benjaminin sukukunnasta, Palti, Rafun poika;

## 4. Mooseksen kirja 13:10

Sebulonin sukukunnasta, Gaddiel, Sodin poika;

## 4. Mooseksen kirja 13:11

Manassen sukukunnasta, joka on osa Joosefia, Gaddi, Susin poika;

## 4. Mooseksen kirja 13:12

Danin sukukunnasta, Ammiel, Gemallin poika;

## 4. Mooseksen kirja 13:13

Asserin sukukunnasta, Setur, Mikaelin poika;

## 4. Mooseksen kirja 13:14

Naftalin sukukunnasta, Nahbi, Vofsin poika;

## 4. Mooseksen kirja 13:15

Gadin sukukunnasta, Geuel, Makin poika.

## 4. Mooseksen kirja 13:16

Nämä ovat miehet, jotka Mooses lähetti tutkimaan maata. Mooses antoi myös Hoosealle, Nuunin pojalle, nimen Joosua.

## 4. Mooseksen kirja 13:17

Kun Mooses lähetti heidät tutkimaan Kanaanin maata, hän käski heitä: "Menkää Negevin kautta ja sitten vuoristoon.

## 4. Mooseksen kirja 13:18

Katsokaa, millainen maa on, ja ovatko siellä asuvat ihmiset vahvoja vai heikkoja, harvalukuisia vai monilukuisia.

## 4. Mooseksen kirja 13:19

Millaisessa maassa he asuvat? Onko se hyvä vai huono? Millaisia kaupungit ovat? Ovatko ne muurettomia vai varustettuja?

## 4. Mooseksen kirja 13:20

Ja millainen on maa? Onko se hedelmällinen vai karu? Onko siellä puita vai ei? Olkaa rohkeita ja tuokaa mukananne maan hedelmiä." Nyt oli ensimmäisten kypsien rypäleiden aika.

## 4. Mooseksen kirja 13:21

Niin he menivät ylös ja tutkivat maata Siinin autiomaasta Rehobiin asti, Lebo-Hamatin suuntaan.

## 4. Mooseksen kirja 13:22

He menivät Negevin kautta ja tulivat Hebroniin, jossa olivat Ahiman, Sesai ja Talmai, Anakin jälkeläiset. (Hebron oli rakennettu seitsemän vuotta ennen Soania Egyptissä.)

## 4. Mooseksen kirja 13:23

Kun he saapuivat Eskolin laaksoon, he leikkasivat sieltä oksan, jossa oli yksi rypäleterttu. Kaksi heistä kantoi sitä tangolla välissään, ja he ottivat mukaansa myös granaattiomenoita ja viikunoita.

## 4. Mooseksen kirja 13:24

Paikkaa kutsuttiin Eskolin laaksoksi sen rypäletertun vuoksi, jonka israelilaiset leikkasivat sieltä.

## 4. Mooseksen kirja 13:25

Neljäkymmenen päivän kuluttua he palasivat tutkimasta maata.

## 4. Mooseksen kirja 13:26

He palasivat Mooseksen ja Aaronin ja koko israelilaisten yhteisön luo Kadesiin, Paranin autiomaahan. Siellä he antoivat heille ja koko seurakunnalle raportin ja näyttivät heille maan hedelmät.

## 4. Mooseksen kirja 13:27

He antoivat Moosekselle tämän kertomuksen: "Me menimme siihen maahan, johon sinä meidät lähetit, ja se todella vuotaa maitoa ja hunajaa. Tässä ovat sen hedelmät.

## 4. Mooseksen kirja 13:28

Kuitenkin siellä asuvat ihmiset ovat voimakkaita, ja kaupungit ovat varustettuja ja erittäin suuria. Näimme siellä jopa Anakin jälkeläisiä.

## 4. Mooseksen kirja 13:29

Amalekilaiset asuvat Negevissä; heettiläiset, jebusilaiset ja amorilaiset asuvat vuoristossa; ja kanaanilaiset asuvat meren rannalla ja Jordanin varrella."

## 4. Mooseksen kirja 13:30

Silloin Kaleb hiljensi kansan Mooseksen edessä ja sanoi: "Meidän pitäisi mennä ylös ja ottaa maa haltuumme, sillä me voimme varmasti voittaa sen."

## 4. Mooseksen kirja 13:31

Mutta miehet, jotka olivat menneet hänen kanssaan, sanoivat: "Emme pysty menemään ylös noita ihmisiä vastaan, sillä he ovat meitä vahvempia."

## 4. Mooseksen kirja 13:32

Ja he levittivät israelilaisten keskuudessa huonoa raporttia maasta, jota he olivat tutkineet, sanoen: "Maa, jota tutkimme, syö asukkaansa, ja kaikki ihmiset, jotka näimme siellä, ovat suurikokoisia.

## 4. Mooseksen kirja 13:33

Näimme siellä jättiläisiä (Anakin jälkeläiset ovat peräisin jättiläisistä). Me näytimme omissa silmissämme heinäsirkoilta, ja niin me näytimme heidänkin silmissään."
