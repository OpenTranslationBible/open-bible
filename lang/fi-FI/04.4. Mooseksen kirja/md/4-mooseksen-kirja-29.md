# 4. Mooseksen kirja Luku 29

## 4. Mooseksen kirja 29:1
‘Seitsemännessä kuussa, kuukauden ensimmäisenä päivänä, teidän tulee pitää pyhä kokous ja pidättäytyä kaikesta tavallisesta työstä. Se on pasuunoiden soiton päivä.

## 4. Mooseksen kirja 29:2
Tarjotkaa polttouhri suloisena tuoksuna Herralle: yksi nuori sonni, yksi pässi ja seitsemän vuoden vanhaa virheetöntä karitsaa.

## 4. Mooseksen kirja 29:3
Sonniin liittyen, tarjotkaa ruokauhri, joka koostuu kolmesta kymmenyksestä eefa hienoa jauhoa öljyn kanssa sekoitettuna; pässiin liittyen, kaksi kymmenystä;

## 4. Mooseksen kirja 29:4
ja kutakin seitsemää karitsaa kohden, yksi kymmenesosa.

## 4. Mooseksen kirja 29:5
Sisällyttäkää yksi urosvuohi syntiuhrina sovituksen saavuttamiseksi teille.

## 4. Mooseksen kirja 29:6
Nämä uhrit ovat lisänä kuukausittaiseen polttouhriin ja sen ruokauhriin sekä jatkuvaan polttouhriin sen ruokauhrin ja juomauhrin kanssa, kuten on määrätty. Ne ovat suloisena tuoksuna, tuliuhri Herralle.

## 4. Mooseksen kirja 29:7
‘Tämän seitsemännen kuun kymmenentenä päivänä teidän tulee pitää pyhä kokous ja nöyrtyä; älkää tehkö työtä.

## 4. Mooseksen kirja 29:8
