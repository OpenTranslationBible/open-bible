# 4. Mooseksen kirja Luku 8

## 4. Mooseksen kirja 8:1

Sitten Herra puhui Moosekselle sanoen,

## 4. Mooseksen kirja 8:2

"Puhele Aaronille ja käske häntä: 'Kun asetat lamput, varmista, että kaikki seitsemän valaisevat lampunjalan edessä olevaa aluetta.'"

## 4. Mooseksen kirja 8:3

Aaron totteli; hän asetti lamput siten, että ne valaisivat lampunjalan edessä, aivan kuten Herra oli Moosekselle käskenyt.

## 4. Mooseksen kirja 8:4

Tällainen oli lampunjalan valmistus: se oli tehty taotusta kullasta, jalustastaan koristeellisiin kukintoihinsa asti. Se oli tehty sen mallin mukaan, jonka Herra oli Moosekselle näyttänyt.

## 4. Mooseksen kirja 8:5

Herra puhui jälleen Moosekselle sanoen,

## 4. Mooseksen kirja 8:6

"Valitse leeviläiset israelilaisten joukosta ja puhdista heidät.

## 4. Mooseksen kirja 8:7

Puhdistaaksesi heidät, tee seuraavasti: pirskota heitä puhdistavalla vedellä, anna heidän ajaa koko ruumiinsa partaveitsellä ja pestä vaatteensa. Näin he puhdistautuvat.

## 4. Mooseksen kirja 8:8

Anna heidän ottaa härkä uhriksi, johon liittyy hienoa jauhoa öljyn kanssa; ja ota toinen härkä syntiuhriksi.

## 4. Mooseksen kirja 8:9

Tuo leeviläiset ilmestysmajan eteen ja kokoa koko israelilaisten yhteisö.

## 4. Mooseksen kirja 8:10

Aseta leeviläiset Herran eteen, ja israelilaiset laskekoot kätensä leeviläisten päälle.

## 4. Mooseksen kirja 8:11

Aaron esittäköön leeviläiset Herran edessä heilutusuhrina israelilaisten puolesta, jotta he olisivat valmiit suorittamaan Herran palvelusta.

## 4. Mooseksen kirja 8:12

Leeviläiset laskekoot kätensä härkien päälle; sitten uhraa toinen syntiuhrina ja toinen polttouhrina Herralle, leeviläisten sovittamiseksi.

## 4. Mooseksen kirja 8:13

Aseta leeviläiset seisomaan Aaronin ja hänen poikiensa eteen ja esitä heidät heilutusuhrina Herralle.

## 4. Mooseksen kirja 8:14

Tällä tavoin erotat leeviläiset muista israelilaisista, ja leeviläiset ovat minun.

## 4. Mooseksen kirja 8:15

Kun olet puhdistanut leeviläiset ja esittänyt heidät heilutusuhrina, he voivat tulla palvelemaan ilmestysmajassa.

## 4. Mooseksen kirja 8:16

Heidät on annettu kokonaan minulle israelilaisten joukosta. Olen ottanut heidät itselleni jokaisen kohdun esikoisen sijasta, kaikkien israelilaisten esikoisten sijasta.

## 4. Mooseksen kirja 8:17

Sillä jokainen esikoinen Israelissa, sekä ihminen että eläin, on minun. Sinä päivänä, kun löin kaikki esikoiset Egyptissä, pyhitin heidät itselleni.

## 4. Mooseksen kirja 8:18

Olen ottanut leeviläiset jokaisen israelilaisen esikoisen sijasta.

## 4. Mooseksen kirja 8:19

Olen antanut leeviläiset lahjaksi Aaronille ja hänen pojilleen israelilaisten joukosta, suorittamaan palvelusta ilmestysmajassa israelilaisten puolesta ja tekemään sovitusta heidän puolestaan, jotta mikään vitsaus ei kohtaisi israelilaisia, kun he lähestyvät pyhäkköä."

## 4. Mooseksen kirja 8:20

Mooses, Aaron ja koko israelilaisten yhteisö tekivät leeviläisten kanssa juuri niin kuin Herra oli Moosekselle käskenyt.

## 4. Mooseksen kirja 8:21

Leeviläiset puhdistautuivat ja pesivät vaatteensa. Aaron esitti heidät heilutusuhrina Herran edessä ja teki sovituksen heidän puolestaan puhdistaakseen heidät.

## 4. Mooseksen kirja 8:22

Sen jälkeen leeviläiset menivät suorittamaan tehtäviään ilmestysmajassa Aaronin ja hänen poikiensa valvonnassa. He tekivät leeviläisten kanssa juuri niin kuin Herra oli Moosekselle käskenyt.

## 4. Mooseksen kirja 8:23

Herra puhui Moosekselle sanoen,

## 4. Mooseksen kirja 8:24

"Tämä koskee leeviläisiä: kaksikymmentäviisivuotiaasta ylöspäin he astukoot palvelemaan ilmestysmajan työssä.

## 4. Mooseksen kirja 8:25

Mutta viidenkymmenen vuoden iässä he vetäytykööt säännöllisestä palveluksesta eivätkä enää työskö.

## 4. Mooseksen kirja 8:26

He voivat avustaa veljiään heidän tehtäviensä täyttämisessä ilmestysmajassa, mutta he eivät itse suorita työtä. Näin sinun tulee jakaa leeviläisten vastuut."
