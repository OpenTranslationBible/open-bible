# 4. Mooseksen kirja Luku 6

## 4. Mooseksen kirja 6:1

Herra puhui jälleen Moosekselle sanoen:

## 4. Mooseksen kirja 6:2

"Puhu israelilaisille ja sano heille: 'Kun mies tai nainen tekee erityisen lupauksen, nasiirilupauksen, omistautuakseen Herralle,

## 4. Mooseksen kirja 6:3

heidän on pidättäydyttävä viinistä ja väkijuomasta; he eivät saa juoda viinietikkaa tai väkijuomaetikkaa, eivätkä he saa nauttia rypälemehua tai syödä tuoreita tai kuivattuja rypäleitä.

## 4. Mooseksen kirja 6:4

Koko lupauksensa ajan he eivät saa syödä mitään, mikä tulee viiniköynnöksestä, eivät edes siemeniä tai kuoria.

## 4. Mooseksen kirja 6:5

"'Koko nasiirilupauksensa ajan partaveitsi ei saa koskea heidän päähänsä. Heidän on oltava pyhiä, kunnes heidän omistautumisensa Herralle on päättynyt; heidän on annettava hiustensa kasvaa pitkiksi.

## 4. Mooseksen kirja 6:6

"'Omistautumisensa aikana Herralle nasiirin ei pidä mennä lähelle kuollutta henkilöä.

## 4. Mooseksen kirja 6:7

He eivät saa saastuttaa itseään isänsä, äitinsä, veljensä tai sisarensa vuoksi, kun nämä kuolevat, koska heidän vihkimyksensä merkki Jumalalle on heidän päässään.

## 4. Mooseksen kirja 6:8

Koko omistautumisensa ajan he ovat pyhiä Herralle.

## 4. Mooseksen kirja 6:9

"'Jos joku kuolee äkillisesti heidän vieressään, saastuttaen heidän vihityn päänsä hiukset, heidän on ajettava päänsä seitsemäntenä päivänä, puhdistautumispäivänään.

## 4. Mooseksen kirja 6:10

Kahdeksantena päivänä heidän on tuotava kaksi metsäkyyhkyä tai kaksi kyyhkysenpoikaa papille ilmestysmajan oven luo.

## 4. Mooseksen kirja 6:11

Pappi uhratkoon toisen syntiuhriksi ja toisen polttouhriksi sovittaakseen heidät, koska he tekivät syntiä olemalla kuolleen henkilön läsnäollessa. Samana päivänä heidän on vihittävä päänsä uudelleen.

## 4. Mooseksen kirja 6:12

Heidän on omistauduttava Herralle uudelleen koko lupauksensa ajaksi ja tuotava vuoden vanha uroskaritsa vikauhriksi. Aiemmat päivät eivät lasketa, koska heidän vihkimyksensä oli saastunut.

## 4. Mooseksen kirja 6:13

"'Tämä on laki nasiirista, kun heidän omistautumisensa aika on päättynyt: Heidät on tuotava ilmestysmajan ovelle.

## 4. Mooseksen kirja 6:14

Siellä heidän on esitettävä uhrinsa Herralle: vuoden vanha virheetön uroskaritsa polttouhriksi, vuoden vanha virheetön naaraskaritsa syntiuhriksi ja virheetön pässi yhteysuhriksi,

## 4. Mooseksen kirja 6:15

sekä kori happamatonta leipää, joka on tehty hienosta jauhosta sekoitettuna öljyyn, ja happamattomia vohveleita voideltuina öljyllä, yhdessä ruokauhriensa ja juomauhriensa kanssa.

## 4. Mooseksen kirja 6:16

"'Pappi esittäköön nämä Herran edessä ja uhratkoon syntiuhrin ja polttouhrin.

## 4. Mooseksen kirja 6:17

Hän uhratkoon myös pässin yhteysuhriksi Herralle, yhdessä happamattoman leivän korin kanssa; pappi esittäköön myös ruokauhrin ja juomauhrin.

## 4. Mooseksen kirja 6:18

"'Nasiirin on sitten ajettava vihityt hiuksensa ilmestysmajan oven luona ja asetettava hiukset tuleen yhteysuhrin alle.

## 4. Mooseksen kirja 6:19

"'Kun nasiiri on ajanut vihityt hiuksensa, papin on asetettava heidän käsiinsä keitetty pässin lapa, yksi happamaton leipä ja yksi happamaton vohveli korista.

## 4. Mooseksen kirja 6:20

Pappi heiluttakoon ne heilutusuhrina Herran edessä; ne ovat pyhiä ja kuuluvat papille, yhdessä heilutetun rinnan ja esitetyn reiden kanssa. Tämän jälkeen nasiiri saa juoda viiniä.

## 4. Mooseksen kirja 6:21

"'Tämä on laki nasiirista, joka lupaa uhreja Herralle omistautumisensa mukaan, lisäksi mitä tahansa muuta he voivat antaa. Heidän on täytettävä tekemänsä lupaus vihkimyksensä lain mukaan.'"

## 4. Mooseksen kirja 6:22

Herra puhui sitten Moosekselle sanoen:

## 4. Mooseksen kirja 6:23

"Puhu Aaronille ja hänen pojilleen sanoen: 'Näin teidän on siunattava israelilaisia. Sanokaa heille:

## 4. Mooseksen kirja 6:24

"'“Herra siunatkoon sinua ja varjelkoon sinua;

## 4. Mooseksen kirja 6:25

Herra kirkastakoon kasvonsa sinulle ja olkoon sinulle armollinen;

## 4. Mooseksen kirja 6:26

Herra kääntäköön kasvonsa sinun puoleesi ja antakoon sinulle rauhan.”'

## 4. Mooseksen kirja 6:27

"Tällä tavoin he asettavat minun nimeni israelilaisten ylle, ja minä siunaan heitä."
