# 4. Mooseksen kirja Luku 9

## 4. Mooseksen kirja 9:1

Herra puhui Moosekselle Siinain erämaassa, toisen vuoden ensimmäisenä kuukautena sen jälkeen, kun he olivat lähteneet Egyptistä, sanoen:

## 4. Mooseksen kirja 9:2

"Israelilaisten tulee viettää pääsiäistä määräaikanaan.

## 4. Mooseksen kirja 9:3

Tämän kuukauden neljäntenätoista päivänä, iltahämärässä, teidän tulee viettää sitä määräaikanaan; teidän tulee viettää se kaikkien sen säädösten ja määräysten mukaisesti."

## 4. Mooseksen kirja 9:4

Niin Mooses käski israelilaisia viettämään pääsiäistä.

## 4. Mooseksen kirja 9:5

Ja he tekivät niin Siinain erämaassa, ensimmäisen kuukauden neljäntenätoista päivänä, iltahämärässä, kaiken sen mukaisesti, mitä Herra oli Moosekselle käskenyt, israelilaiset tekivät.

## 4. Mooseksen kirja 9:6

Kuitenkin jotkut miehet olivat epäpuhtaita kosketuksesta kuolleeseen ruumiiseen, eivätkä he voineet viettää pääsiäistä sinä päivänä. He lähestyivät Moosesta ja Aaronia sinä päivänä

## 4. Mooseksen kirja 9:7

ja sanoivat: "Me olemme epäpuhtaita kuolleen ruumiin vuoksi, mutta miksi meidät pitäisi sulkea pois Herran uhrin esittämisestä sen määräaikana muiden israelilaisten kanssa?"

## 4. Mooseksen kirja 9:8

Mooses vastasi: "Odottakaa tässä, kunnes kuulen, mitä Herra käskee teistä."

## 4. Mooseksen kirja 9:9

Sitten Herra puhui Moosekselle ja sanoi:

## 4. Mooseksen kirja 9:10

"Puhu israelilaisille ja sano: 'Jos joku teistä tai teidän jälkeläisistänne on epäpuhdas kuolleen ruumiin vuoksi tai on matkalla, he voivat silti viettää pääsiäistä Herralle.

## 4. Mooseksen kirja 9:11

Toisen kuukauden neljäntenätoista päivänä, iltahämärässä, heidän tulee viettää sitä; heidän tulee syödä sitä happamattoman leivän ja karvaiden yrttien kanssa.

## 4. Mooseksen kirja 9:12

He eivät saa jättää siitä mitään aamuun asti, eivätkä rikkoa siitä yhtäkään luuta. Heidän tulee viettää se kaikkien pääsiäisen säädösten mukaisesti.

## 4. Mooseksen kirja 9:13

Mutta jos joku on puhdas eikä ole matkalla ja pidättäytyy viettämästä pääsiäistä, se henkilö erotettakoon kansastaan, koska hän ei ole esittänyt Herran uhria sen määräaikana. Hän kantaa syntinsä syyllisyyden.

## 4. Mooseksen kirja 9:14

Jos muukalainen asuu teidän keskuudessanne ja haluaa viettää pääsiäistä Herralle, hänen tulee tehdä se sen säädösten ja määräysten mukaisesti. Teillä tulee olla sama laki sekä muukalaiselle että maassa syntyneelle.'"

## 4. Mooseksen kirja 9:15

Sinä päivänä, kun tabernaakkeli, todistuksen teltta, pystytettiin, pilvi peitti sen. Illasta aamuun asti pilvi tabernaakkelin yllä näytti tulelta.

## 4. Mooseksen kirja 9:16

Tämä oli säännöllinen kaava; pilvi peitti sen päivällä, ja yöllä se näytti tulelta.

## 4. Mooseksen kirja 9:17

Aina kun pilvi nousi teltan yläpuolelta, israelilaiset lähtivät liikkeelle; ja minne pilvi asettui, sinne israelilaiset leiriytyivät.

## 4. Mooseksen kirja 9:18

Herran käskystä israelilaiset lähtivät liikkeelle, ja hänen käskystään he leiriytyivät. Niin kauan kuin pilvi pysyi tabernaakkelin yllä, he pysyivät leiriytyneinä.

## 4. Mooseksen kirja 9:19

Vaikka pilvi viipyi tabernaakkelin yllä monta päivää, israelilaiset noudattivat Herran käskyä eivätkä lähteneet liikkeelle.

## 4. Mooseksen kirja 9:20

Joskus pilvi oli tabernaakkelin yllä vain muutaman päivän, Herran käskystä he leiriytyivät, ja sitten hänen käskystään he lähtivät liikkeelle.

## 4. Mooseksen kirja 9:21

Jos pilvi pysyi vain illasta aamuun, kun se nousi aamulla, he lähtivät liikkeelle. Päivällä tai yöllä, aina kun pilvi nousi, he lähtivät liikkeelle.

## 4. Mooseksen kirja 9:22

Olipa se kaksi päivää, kuukausi tai vuosi, jonka pilvi pysyi tabernaakkelin yllä, israelilaiset pysyivät leiriytyneinä eivätkä lähteneet liikkeelle; mutta kun se nousi, he lähtivät liikkeelle.

## 4. Mooseksen kirja 9:23

Herran käskystä he leiriytyivät, ja Herran käskystä he lähtivät liikkeelle. He noudattivat Herran ohjeita, hänen käskynsä mukaisesti Mooseksen kautta.
