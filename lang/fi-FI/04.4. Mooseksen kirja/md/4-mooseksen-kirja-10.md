# 4. Mooseksen kirja Luku 10

## 4. Mooseksen kirja 10:1

Herra puhui Moosekselle sanoen:

## 4. Mooseksen kirja 10:2

"Tee itsellesi kaksi hopeatorvea, jotka ovat taottua hopeaa; käytä niitä kutsuaksesi seurakunta koolle ja leirin purkamiseksi.

## 4. Mooseksen kirja 10:3

Kun molempia torvia puhalletaan, koko seurakunta kokoontuu sinun eteesi ilmestysmajan oven luo.

## 4. Mooseksen kirja 10:4

Jos vain yhtä torvea puhalletaan, kokoontuvat sinun eteesi Israelin heimojen päämiehet, tuhannenpäämiehet.

## 4. Mooseksen kirja 10:5

Kun puhalletaan hälytys, lähtevät liikkeelle ne leirit, jotka ovat itäpuolella.

## 4. Mooseksen kirja 10:6

Kun hälytys puhalletaan toisen kerran, lähtevät liikkeelle ne leirit, jotka ovat eteläpuolella. Hälytys on puhallettava heidän liikkeellelähtöään varten.

## 4. Mooseksen kirja 10:7

Kun kokoonnutaan seurakuntaan, puhalletaan torviin, mutta ei hälytystä.

## 4. Mooseksen kirja 10:8

Aaronin pojat, papit, puhaltavat torviin. Tämä on oleva teille ikuinen säädös sukupolvesta sukupolveen.

## 4. Mooseksen kirja 10:9

Kun te lähdette sotaan omassa maassanne vihollista vastaan, joka ahdistaa teitä, puhaltakaa hälytys torvilla. Silloin teidät muistetaan Herran, teidän Jumalanne, edessä ja te pelastutte vihollisistanne.

## 4. Mooseksen kirja 10:10

Iloitsemisen päivinä, juhlapäivinä ja kuukausienne alussa teidän tulee puhaltaa torviin polttouhrienne ja yhteysuhriinne yli, ja ne ovat muistutuksena teidän Jumalanne edessä. Minä olen Herra, teidän Jumalanne."

## 4. Mooseksen kirja 10:11

Toisena vuotena, toisen kuukauden kahdentenakymmenentenä päivänä, pilvi kohosi liiton lain asumuksen päältä.

## 4. Mooseksen kirja 10:12

Israelilaiset lähtivät liikkeelle Siinain autiomaasta ja kulkivat paikasta toiseen, kunnes pilvi pysähtyi Paranin autiomaahan.

## 4. Mooseksen kirja 10:13

He lähtivät liikkeelle ensimmäistä kertaa Herran käskystä Mooseksen kautta.

## 4. Mooseksen kirja 10:14

Juudan leirin lippukunta lähti liikkeelle ensin joukko-osastoittain, ja Nahson, Amminadabin poika, oli sen johdossa.

## 4. Mooseksen kirja 10:15

Issakarin heimon joukko-osastoa johti Netanel, Suarin poika,

## 4. Mooseksen kirja 10:16

ja Sebulonin heimon joukko-osastoa johti Eliab, Helonin poika.

## 4. Mooseksen kirja 10:17

Sitten asumus purettiin, ja Gershonilaiset ja Merarilaiset, jotka kantoivat sitä, lähtivät liikkeelle.

## 4. Mooseksen kirja 10:18

Rubenin leirin lippukunta lähti liikkeelle seuraavaksi joukko-osastoittain, ja Elisur, Sedeurin poika, oli sen johdossa.

## 4. Mooseksen kirja 10:19

Simeonin heimon joukko-osastoa johti Selumiel, Surisaddain poika,

## 4. Mooseksen kirja 10:20

ja Gadin heimon joukko-osastoa johti Eljasaf, Deuelin poika.

## 4. Mooseksen kirja 10:21

Sitten Kehatilaiset lähtivät liikkeelle kantaen pyhiä esineitä. Asumus oli pystytettävä ennen heidän saapumistaan.

## 4. Mooseksen kirja 10:22

Efraimin leirin lippukunta lähti liikkeelle seuraavaksi joukko-osastoittain, ja Elisama, Ammihudin poika, oli sen johdossa.

## 4. Mooseksen kirja 10:23

Manassen heimon joukko-osastoa johti Gamliel, Pedasurin poika,

## 4. Mooseksen kirja 10:24

ja Benjaminin heimon joukko-osastoa johti Abidan, Gideonin poika.

## 4. Mooseksen kirja 10:25

Viimeisenä lähti liikkeelle Danin leirin lippukunta, joka muodosti kaikkien leirien jälkivartioston, joukko-osastoittain, ja Ahieser, Ammisaddain poika, oli sen johdossa.

## 4. Mooseksen kirja 10:26

Asserin heimon joukko-osastoa johti Pagiel, Okranin poika,

## 4. Mooseksen kirja 10:27

ja Naftalin heimon joukko-osastoa johti Ahira, Enanin poika.

## 4. Mooseksen kirja 10:28

Tämä oli israelilaisten joukko-osastojen marssijärjestys heidän lähtiessään liikkeelle.

## 4. Mooseksen kirja 10:29

Mooses sanoi midianilaiselle Reuelin pojalle Hobabille, Mooseksen appiukolle: "Me olemme lähdössä siihen paikkaan, jonka Herra on luvannut antaa meille. Tule mukaamme, niin me kohtelemme sinua hyvin, sillä Herra on luvannut hyviä asioita Israelille."

## 4. Mooseksen kirja 10:30

Hän vastasi: "En lähde; minä palaan omaan maahani ja omaan kansaani."

## 4. Mooseksen kirja 10:31

Mooses pyysi: "Älä jätä meitä. Sinä tiedät, mihin meidän tulee leiriytyä autiomaassa, ja voit olla oppaanamme.

## 4. Mooseksen kirja 10:32

Jos tulet mukaamme, jaamme kanssasi kaiken hyvän, mitä Herra meille antaa."

## 4. Mooseksen kirja 10:33

Niin he lähtivät Herran vuorelta ja matkustivat kolme päivää. Herran liitonarkki kulki heidän edellään nuo kolme päivää etsien heille lepopaikkaa.

## 4. Mooseksen kirja 10:34

Herran pilvi oli heidän yllään päivällä heidän lähtiessään leiristä.

## 4. Mooseksen kirja 10:35

Aina kun arkki lähti liikkeelle, Mooses sanoi: "Nouse, Herra! Hajotkoot sinun vihollisesi ja paetkoot sinun vihamiehesi sinun edestäsi."

## 4. Mooseksen kirja 10:36

Aina kun se pysähtyi, hän sanoi: "Palaa, Herra, Israelin tuhansien joukkoon."
