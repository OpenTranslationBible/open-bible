# 4. Mooseksen kirja Luku 34

## 4. Mooseksen kirja 34:1

Herra puhui Moosekselle sanoen nämä sanat:

## 4. Mooseksen kirja 34:2

"Käske israelilaisia ja sano heille: 'Kun tulette Kanaanin maahan, tämä on se maa, joka jaetaan teille perintöosaksi, näillä rajoilla:

## 4. Mooseksen kirja 34:3

'Etelärajananne olkoon Sinin erämaa Edomin rajaa pitkin, ja eteläraja alkakoon Suolameren itäpäästä,

## 4. Mooseksen kirja 34:4

kulkee Akrabbimin nousun eteläpuolelta, jatkuu Siniin ja menee Kades-Barnean eteläpuolelta. Sitten se ulottuu Hazar-Addariin ja jatkuu Asmoniin,

## 4. Mooseksen kirja 34:5

missä se kääntyy ja liittyy Egyptin puroon, päättyen Välimereen.

## 4. Mooseksen kirja 34:6

'Länsirajananne olkoon Välimereen rannikko. Tämä olkoon rajanne lännessä.

## 4. Mooseksen kirja 34:7

'Pohjoisrajanne kulkekoon Välimereen Mount Horille.

## 4. Mooseksen kirja 34:8

Mount Horilta vetäkää raja Lebo-Hamathiin, ja raja ulottuu Sedadiin,

## 4. Mooseksen kirja 34:9

jatkuu Sifraniin ja päättyy Hazar-Enaniin. Tämä olkoon rajanne pohjoisessa.

## 4. Mooseksen kirja 34:10

'Itärajanne kulkekoon Hazar-Enanista Sefamiin.

## 4. Mooseksen kirja 34:11

Raja laskeutuu Sefamista Riblahiin Ainista itään ja jatkuu Galilean meren itäpuolisia rinteitä pitkin.

## 4. Mooseksen kirja 34:12

Sitten raja laskeutuu Jordanin vartta ja päättyy Suolamereen. 'Tämä olkoon maanne, rajoinensa joka puolella.'"

## 4. Mooseksen kirja 34:13

Mooses käski israelilaisia: "Jakakaa tämä maa arvalla perintöosaksi, kuten Herra on käskenyt antaa yhdeksälle ja puolelle heimolle.

## 4. Mooseksen kirja 34:14

Sillä Ruubenin heimo, Gadin heimo ja puolet Manassen heimosta ovat saaneet perintöosansa perheittensä mukaan.

## 4. Mooseksen kirja 34:15

Nämä kaksi ja puoli heimoa ovat saaneet perintöosansa Jordanin itäpuolella Jerikoa vastapäätä, auringonnousun suuntaan."

## 4. Mooseksen kirja 34:16

Herra puhui Moosekselle sanoen nämä sanat:

## 4. Mooseksen kirja 34:17

"Nämä ovat niiden miesten nimet, jotka jakavat teille maan perintöosaksi: pappi Eleasar ja Joosua, Nunin poika.

## 4. Mooseksen kirja 34:18

Nimetkää johtaja kustakin heimosta auttamaan maan jakamisessa.

## 4. Mooseksen kirja 34:19

Nimet ovat seuraavat: Juudan heimosta, Kaaleb, Jefunnen poika;

## 4. Mooseksen kirja 34:20

Simeonin heimosta, Semuel, Ammihudin poika;

## 4. Mooseksen kirja 34:21

Benjaminin heimosta, Elidad, Kislonin poika;

## 4. Mooseksen kirja 34:22

Danin heimosta, johtaja, Bukki, Joglin poika;

## 4. Mooseksen kirja 34:23

Manassen heimosta, johtaja, Hanniel, Efodin poika;

## 4. Mooseksen kirja 34:24

Efraimin heimosta, johtaja, Kemuel, Siftanin poika;

## 4. Mooseksen kirja 34:25

Sebulonin heimosta, johtaja, Elisafan, Parnakin poika;

## 4. Mooseksen kirja 34:26

Isaskarin heimosta, johtaja, Paltiel, Assanin poika;

## 4. Mooseksen kirja 34:27

Asserin heimosta, johtaja, Ahihud, Selomin poika;

## 4. Mooseksen kirja 34:28

Naftalin heimosta, johtaja, Pedahel, Ammihudin poika."

## 4. Mooseksen kirja 34:29

Nämä ovat ne miehet, jotka Herra käski jakamaan perintöosan israelilaisille Kanaanin maassa.
