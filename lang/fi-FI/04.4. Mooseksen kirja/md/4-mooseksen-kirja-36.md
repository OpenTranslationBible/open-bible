# 4. Mooseksen kirja Luku 36

## 4. Mooseksen kirja 36:1
Gileadin, Makirin pojan, Manassen pojan perheiden isien sukukuntien päämiehet, Joosefin jälkeläisten suvuista, lähestyivät ja puhuivat Mooseksen ja johtajien, israelilaisten perheiden päämiesten, edessä.

## 4. Mooseksen kirja 36:2
He sanoivat: "Herra käski herrani jakaa maan israelilaisille perintönä arpomalla, ja herrani sai Herralta käskyn antaa veljemme Selofhadin perintö hänen tyttärilleen.

## 4. Mooseksen kirja 36:3
Mutta jos he menevät naimisiin muiden israelilaisten heimojen miesten kanssa, heidän perintönsä otetaan pois meidän esi-isiemme perinnöstä ja lisätään siihen heimoon, johon he menevät naimisiin, ja näin meidän määrätty perintömme vähenee.

## 4. Mooseksen kirja 36:4
Kun israelilaisten riemuvuosi koittaa, heidän perintönsä lisätään siihen heimoon, johon he menevät naimisiin, ja heidän omaisuutensa otetaan pois meidän esi-isiemme heimon perinnöstä."

## 4. Mooseksen kirja 36:5
Mooses välitti sitten Herran käskyn israelilaisille sanoen: "Joosefin jälkeläisten heimo on oikeassa väitteissään.

## 4. Mooseksen kirja 36:6
Tämä on se, mitä Herra käskee Selofhadin tyttäristä: He voivat mennä naimisiin kenen kanssa haluavat, kunhan menevät naimisiin isänsä heimoon kuuluvan kanssa.

## 4. Mooseksen kirja 36:7
Näin mikään perintö Israelissa ei siirry heimolta toiselle, sillä jokaisen israelilaisen tulee säilyttää esi-isiensä heimon perintö.

## 4. Mooseksen kirja 36:8
Jokaisen israelilaisen heimon perinnön saavan tyttären tulee mennä naimisiin isänsä heimon jäsenen kanssa, jotta jokainen israelilainen voi säilyttää esi-isiensä perinnön.

## 4. Mooseksen kirja 36:9
Mikään perintö ei saa siirtyä heimolta toiselle, sillä jokaisen israelilaisen heimon on pidettävä oma perintönsä."

## 4. Mooseksen kirja 36:10
Selofhadin tyttäret toimivat niin kuin Herra oli käskenyt Mooseksen.

## 4. Mooseksen kirja 36:11
Mahlah, Tirsa, Hogla, Milka ja Nooa, Selofhadin tyttäret, menivät naimisiin isänsä puoleisten serkkujensa kanssa.

## 4. Mooseksen kirja 36:12
He menivät naimisiin Joosefin pojan Manassen jälkeläisten perheisiin, ja heidän perintönsä pysyi heidän isänsä heimossa ja perheessä.

## 4. Mooseksen kirja 36:13
Nämä ovat ne käskyt ja säädökset, jotka Herra antoi israelilaisille Mooseksen kautta Moabin tasangoilla Jordanin varrella, Jerikoa vastapäätä.
