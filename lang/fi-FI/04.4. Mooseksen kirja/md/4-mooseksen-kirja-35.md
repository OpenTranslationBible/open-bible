# 4. Mooseksen kirja Luku 35

## 4. Mooseksen kirja 35:1
Herra puhui Moosekselle Moabin tasangoilla Jordanin varrella, Jerikoa vastapäätä, sanoen:

## 4. Mooseksen kirja 35:2
"Käske israelilaisia antamaan leeviläisille kaupunkeja asuttaviksi heidän perintöosistaan. Antakaa heille myös laidunmaita näiden kaupunkien ympäriltä.

## 4. Mooseksen kirja 35:3
Nämä kaupungit ovat heille asumista varten, ja laidunmaat ovat heidän karjaansa, varusteitaan ja kaikkia muita eläimiään varten.

## 4. Mooseksen kirja 35:4
"Leeviläisille annettavien kaupunkien ympärillä olevat laidunmaat ulottuvat tuhat kyynärää kaupungin muurista ulospäin.

## 4. Mooseksen kirja 35:5
Mitatkaa kaksi tuhatta kyynärää kaupungin ulkopuolelle itään, etelään, länteen ja pohjoiseen, niin että kaupunki on keskellä. Tämä alue toimii laidunmaana kaupungeille.

## 4. Mooseksen kirja 35:6
"Niistä kaupungeista, jotka annatte leeviläisille, määrätkää kuusi turvakaupungeiksi, joihin tappaja voi paeta. Lisäksi antakaa neljäkymmentä kaksi muuta kaupunkia.

## 4. Mooseksen kirja 35:7
Yhteensä teidän on annettava leeviläisille neljäkymmentä kahdeksan kaupunkia laidunmaineen.

## 4. Mooseksen kirja 35:8
Ne kaupungit, jotka annatte leeviläisille israelilaisten maasta, tulee olla suhteessa kunkin heimon perintöosaan: ottakaa enemmän kaupunkeja suuremman perintöosan saaneelta heimolta ja vähemmän pienemmän perintöosan saaneelta.”

## 4. Mooseksen kirja 35:9
Herra puhui sitten Moosekselle sanoen:

## 4. Mooseksen kirja 35:10
"Kerro israelilaisille: 'Kun ylitätte Jordanin Kanaanin maahan,

## 4. Mooseksen kirja 35:11
valitkaa kaupunkeja turvakaupungeiksi, joihin tahaton tappaja voi paeta.

## 4. Mooseksen kirja 35:12
Nämä kaupungit ovat turvapaikka kostajalta, jotta syytetty ei kuolisi ennen kuin hänet on tuomittu seurakunnan edessä.

## 4. Mooseksen kirja 35:13
Ne kuusi kaupunkia, jotka annatte, ovat turvakaupunkeja.

## 4. Mooseksen kirja 35:14
Määrätkää kolme kaupunkia Jordanin tällä puolella ja kolme Kanaanin maassa turvakaupungeiksi.

## 4. Mooseksen kirja 35:15
Nämä kuusi kaupunkia ovat turvapaikka israelilaisille, muukalaisille ja keskuudessanne asuville vierasmaalaisille, jotta kuka tahansa tahaton tappaja voi paeta sinne.

## 4. Mooseksen kirja 35:16
"Jos joku lyö toista rautaesineellä aiheuttaen kuoleman, hän on murhaaja; murhaaja on surmattava.

## 4. Mooseksen kirja 35:17
Jos joku lyö toista kädessään olevalla kivellä aiheuttaen kuoleman, hän on murhaaja; murhaaja on surmattava.

## 4. Mooseksen kirja 35:18
Tai jos joku lyö toista kädessään olevalla puuesineellä aiheuttaen kuoleman, hän on murhaaja; murhaaja on surmattava.

## 4. Mooseksen kirja 35:19
Veren kostaja on surmattava murhaaja; kun kostaja kohtaa murhaajan, hänen on surmattava murhaaja.

## 4. Mooseksen kirja 35:20
Jos joku työntää toista vihasta tai heittää jotain häntä kohti pahantahtoisesti, aiheuttaen kuoleman,

## 4. Mooseksen kirja 35:21
tai jos joku lyö toista vihamielisesti aiheuttaen kuoleman, tekijä on murhaaja ja on surmattava. Veren kostaja on surmattava murhaaja, kun he kohtaavat.

## 4. Mooseksen kirja 35:22
"Jos kuitenkin joku työntää toista äkisti ilman vihamielisyyttä tai heittää esineen häntä kohti ilman pahantahtoisuutta,

## 4. Mooseksen kirja 35:23
tai, näkemättä häntä, pudottaa kiven, joka on tarpeeksi raskas aiheuttamaan kuoleman, ja henkilö kuolee, mutta ei ollut vihamielisyyttä eikä pahaa aikomusta,

## 4. Mooseksen kirja 35:24
niin seurakunnan on tuomittava syytetty ja veren kostaja näiden lakien mukaan.

## 4. Mooseksen kirja 35:25
Seurakunnan on suojeltava taposta syytettyä veren kostajalta ja palautettava syytetty turvakaupunkiin, johon hän pakeni. Syytetyn on pysyttävä siellä ylimmäisen papin kuolemaan asti, joka oli voideltu pyhällä öljyllä.

## 4. Mooseksen kirja 35:26
"Jos syytetty koskaan poistuu turvakaupungin rajoilta, johon hän pakeni,

## 4. Mooseksen kirja 35:27
ja veren kostaja löytää hänet kaupungin ulkopuolelta, kostaja voi tappaa syytetyn syyllistymättä murhaan.

## 4. Mooseksen kirja 35:28
Syytetyn on pysyttävä turvakaupungissa ylimmäisen papin kuolemaan asti; vasta ylimmäisen papin kuoleman jälkeen hän voi palata omaisuudelleen.

## 4. Mooseksen kirja 35:29
"Nämä säädökset ovat teille lakina sukupolvesta toiseen, missä ikinä asuttekin.

## 4. Mooseksen kirja 35:30
"Jokainen, joka tappaa toisen, on surmattava murhaajana vain todistajien lausunnon perusteella. Ketään ei saa surmata vain yhden todistajan lausunnon perusteella.

## 4. Mooseksen kirja 35:31
"Älkää ottako lunnaita murhaajan hengestä, joka ansaitsee kuoleman. Hänet on surmattava.

## 4. Mooseksen kirja 35:32
"Älkää ottako lunnaita keneltäkään, joka on paennut turvakaupunkiin, sallien hänen palata ja asua omalla maallaan ennen ylimmäisen papin kuolemaa.

## 4. Mooseksen kirja 35:33
"Älkää saastuttako maata, jossa asutte. Verenvuodatus saastuttaa maan, eikä maalle, jossa verta on vuodatettu, voida tehdä sovitusta, paitsi sen veren kautta, joka sen vuodatti.

## 4. Mooseksen kirja 35:34
Älkää saastuttako maata, jossa asutte, jossa minäkin asun, sillä minä, Herra, asun israelilaisten keskuudessa.'"
