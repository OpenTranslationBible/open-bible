# 4. Mooseksen kirja Luku 1

## 4. Mooseksen kirja 1:1

Herra puhui Moosekselle Siinain autiomaassa ilmestysmajassa toisen kuukauden ensimmäisenä päivänä toisena vuotena sen jälkeen, kun israelilaiset olivat lähteneet Egyptistä, sanoen:

## 4. Mooseksen kirja 1:2

"Ota koko Israelin seurakunnasta väestönlaskenta heidän perhekuntiensa mukaan, isien sukukunnittain, luetellen jokainen mies nimeltä, yksi kerrallaan.

## 4. Mooseksen kirja 1:3

Sinun ja Aaronin tulee laskea kaikki Israelin miehet, jotka ovat kaksikymmentä vuotta vanhoja tai vanhempia ja kykeneviä palvelemaan armeijassa, heidän osastojensa mukaan.

## 4. Mooseksen kirja 1:4

Kanssasi tulee olla mies kustakin heimosta, jokainen oman perheensä päämies.

## 4. Mooseksen kirja 1:17

## 4. Mooseksen kirja 1:18

ja he kokosivat koko seurakunnan toisen kuukauden ensimmäisenä päivänä. He rekisteröivät sukuluettelojen mukaan perheittensä, isiensä sukukuntien mukaan, nimien lukumäärän mukaan, kaksikymmentä vuotta vanhat ja sitä vanhemmat, yksi kerrallaan,

## 4. Mooseksen kirja 1:19

niin kuin Herra oli Moosekselle käskenyt. Niin hän laski heidät Siinain autiomaassa.

## 4. Mooseksen kirja 1:20

Ruubenin jälkeläisistä, Israelin esikoisesta: Kaikki kaksikymmentä vuotta vanhat tai vanhemmat miehet, jotka kykenivät palvelemaan armeijassa, lueteltiin nimeltä, yksi kerrallaan, heidän sukujensa ja perhekuntiensa mukaan.

## 4. Mooseksen kirja 1:21

Ruubenin heimon lukumäärä oli 46 500.

## 4. Mooseksen kirja 1:22

Sillä Herra oli puhunut Moosekselle, ohjeistaen häntä,

## 4. Mooseksen kirja 1:49

"Älä laske Leevin heimoa äläkä ota heitä mukaan muiden israelilaisten väestönlaskentaan.

## 4. Mooseksen kirja 1:50

Sen sijaan määrää leeviläiset todistuksen tabernaakkelin, kaikkien sen kalusteiden ja kaiken siihen kuuluvan ylle. Heidän tulee kantaa tabernaakkeli ja kaikki sen kalusteet; heidän tulee huolehtia siitä ja leiriytyä sen ympärille.

## 4. Mooseksen kirja 1:51

Aina kun tabernaakkeli on siirrettävä, leeviläisten tulee purkaa se, ja aina kun se on pystytettävä, leeviläisten tulee tehdä se. Jokainen ulkopuolinen, joka lähestyy sitä, on surmattava.

## 4. Mooseksen kirja 1:52

Israelilaisten tulee leiriytyä osastoittain, kukin mies oman leirinsä ja oman lippunsa mukaan.

## 4. Mooseksen kirja 1:53

Mutta leeviläisten tulee leiriytyä todistuksen tabernaakkelin ympärille, jotta ei tulisi jumalallista vihaa israelilaisten seurakuntaa vastaan. Leeviläisten tulee vastata todistuksen tabernaakkelin palveluksesta."

## 4. Mooseksen kirja 1:54

Israelilaiset tekivät kaiken tämän juuri niin kuin Herra oli Moosekselle käskenyt.
