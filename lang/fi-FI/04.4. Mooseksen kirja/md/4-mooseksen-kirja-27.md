# 4. Mooseksen kirja Luku 27

## 4. Mooseksen kirja 27:1

Heferin pojan Selofhadin tyttäret, jotka olivat Gileadin poika, Makirin poika, Manassen poika, Joosefin pojan Manassen suvuista, astuivat esiin. Tytärten nimet olivat Mahla, Nooa, Hogla, Milka ja Tirsa.

## 4. Mooseksen kirja 27:2

He seisoivat Mooseksen, pappi Eleasarin, johtajien ja koko seurakunnan edessä ilmestysmajan ovella ja sanoivat,

## 4. Mooseksen kirja 27:3

"Isämme kuoli erämaassa. Hän ei ollut niiden joukossa, jotka kokoontuivat Herraa vastaan Korahin kanssa, vaan hän kuoli oman syntinsä tähden eikä jättänyt poikia.

## 4. Mooseksen kirja 27:4

Miksi isämme nimi katoaisi hänen suvustaan, koska hänellä ei ollut poikaa? Anna meille perintöosa isämme sukulaisten joukosta."

## 4. Mooseksen kirja 27:5

Mooses vei heidän asiansa Herran eteen.

## 4. Mooseksen kirja 27:6

Herra puhui sitten Moosekselle sanoen,

## 4. Mooseksen kirja 27:7

"Selofhadin tyttäret puhuvat oikein. Sinun tulee antaa heille perintöosa heidän isänsä veljien joukosta ja siirtää heidän isänsä perintö heille.

## 4. Mooseksen kirja 27:8

Puhu israelilaisille sanoen: 'Jos mies kuolee eikä hänellä ole poikaa, siirtäkää hänen perintönsä hänen tyttärelleen.

## 4. Mooseksen kirja 27:9

Mutta jos ei ole tytärtä, antakaa hänen perintönsä hänen veljilleen.

## 4. Mooseksen kirja 27:10

Jos hänellä ei ole veljiä, antakaa hänen perintönsä hänen isänsä veljille.

## 4. Mooseksen kirja 27:11

Jos hänen isällään ei ollut veljiä, antakaa hänen perintönsä hänen lähimmälle sukulaiselleen hänen suvustaan, ja hän omistakoon sen. Tämä olkoon israelilaisille säädöksenä, kuten Herra käski Moosesta.'"

## 4. Mooseksen kirja 27:12

Herra sanoi Moosekselle: "Nouse tälle vuorelle Abarimin alueella ja katso maata, jonka olen antanut israelilaisille.

## 4. Mooseksen kirja 27:13

Kun olet nähnyt sen, liityt esi-isiesi joukkoon, kuten veljesi Aaron teki,

## 4. Mooseksen kirja 27:14

koska kapinoit käskyäni vastaan Meriban vesillä Tsinin erämaassa, etkä pitänyt pyhyyttäni yllä israelilaisten edessä." (Nämä ovat Meriban vedet Kadesissa Tsinin erämaassa.)

## 4. Mooseksen kirja 27:15

Mooses puhui sitten Herralle,

## 4. Mooseksen kirja 27:16

"Herra, Jumala, joka antaa elämän kaikille, asettakoon johtajan yhteisön ylle,

## 4. Mooseksen kirja 27:17

joka vie heidät ulos ja tuo heidät sisään, ettei Herran kansa olisi kuin lammaslauma ilman paimenta."

## 4. Mooseksen kirja 27:18

Herra sanoi Moosekselle: "Ota Nunin poika Joosua, mies, jossa on henki, ja laske kätesi hänen päälleen.

## 4. Mooseksen kirja 27:19

Aseta hänet pappi Eleasarin ja koko seurakunnan eteen, ja anna hänelle tehtävä heidän nähtensä.

## 4. Mooseksen kirja 27:20

Anna hänelle osa auktoriteetistasi, jotta koko israelilaisten yhteisö tottelee häntä.

## 4. Mooseksen kirja 27:21

Hän seisokoon pappi Eleasarin edessä, joka kysyy hänelle päätöksen Urimin kautta Herran edessä. Hänen käskystään he menevät ulos, ja hänen käskystään he tulevat sisään, sekä hän että koko israelilaisten yhteisö."

## 4. Mooseksen kirja 27:22

Mooses teki niin kuin Herra oli käskenyt häntä. Hän otti Joosuan ja asetti hänet pappi Eleasarin ja koko seurakunnan eteen.

## 4. Mooseksen kirja 27:23

Hän laski kätensä hänen päälleen ja antoi hänelle tehtävän, kuten Herra oli Mooseksen kautta käskenyt.
