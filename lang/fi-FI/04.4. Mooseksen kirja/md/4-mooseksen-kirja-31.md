# 4. Mooseksen kirja Luku 31

## 4. Mooseksen kirja 31:1

Herra puhui Moosekselle sanoen:

## 4. Mooseksen kirja 31:2

"Ota kosto midianilaisilta israelilaisten puolesta; sen jälkeen sinut kootaan kansasi tykö."

## 4. Mooseksen kirja 31:3

Mooses puhui kansalle: "Varustakaa miehiä sotaan, että he voivat lähteä Midiania vastaan toteuttamaan Herran kostoa.

## 4. Mooseksen kirja 31:4

Lähettäkää tuhannen miehen joukko kustakin Israelin heimosta taisteluun."

## 4. Mooseksen kirja 31:5

Niin valittiin Israelin tuhansista, tuhat kustakin heimosta, yhteensä kaksitoistatuhatta aseistettua miestä taisteluun.

## 4. Mooseksen kirja 31:6

Mooses lähetti heidät sotaan, tuhat kustakin heimosta, ja heidän kanssaan Eleasarin pojan Pinehaan, pappi, joka otti mukaansa pyhät esineet ja torvet hälytyksen antamista varten.

## 4. Mooseksen kirja 31:7

He kävivät sotaa Midiania vastaan, kuten Herra oli Moosekselle käskenyt, ja tappoivat kaikki miehet.

## 4. Mooseksen kirja 31:8

He tappoivat Midianin kuninkaat, Evin, Rekemin, Surin, Hurin ja Reban, Midianin viisi kuningasta. He tappoivat myös Beorin pojan Bileamin miekalla.

## 4. Mooseksen kirja 31:9

Israelilaiset ottivat vangiksi Midianin naiset ja heidän lapsensa, ja he ryöstivät kaikki heidän karjansa, laumansa ja tavaransa.

## 4. Mooseksen kirja 31:10

He polttivat kaikki heidän asuinpaikkansa ja kaikki heidän leirinsä.

## 4. Mooseksen kirja 31:11

He ottivat kaiken saaliin ja kaiken ryöstetyn, sekä ihmiset että karjan,

## 4. Mooseksen kirja 31:12

ja toivat vangit, saaliin ja ryöstetyn Mooseksen, pappi Eleasarin ja israelilaisten seurakunnan eteen leiriin Mooabin arolle, Jordanin luo vastapäätä Jerikoa.

## 4. Mooseksen kirja 31:13

Mooses, pappi Eleasar ja kaikki seurakunnan johtajat menivät heitä vastaan leirin ulkopuolelle.

## 4. Mooseksen kirja 31:14

Mooses vihastui sotajoukon päälliköille, tuhannen- ja sadanpäämiehille, jotka palasivat sodasta.

## 4. Mooseksen kirja 31:15

Hän sanoi heille: "Oletteko säästäneet kaikki naiset?

## 4. Mooseksen kirja 31:16

Katso, he olivat ne, jotka Bileamin neuvosta saivat israelilaiset luopumaan Herrasta Peorissa, niin että vitsaus kohtasi Herran kansaa.

## 4. Mooseksen kirja 31:17

Tappakaa siis kaikki poikalapset ja kaikki naiset, jotka ovat maanneet miehen kanssa.

## 4. Mooseksen kirja 31:18

Mutta kaikki tyttöpuoliset lapset, jotka eivät ole maanneet miehen kanssa, pitäkää elossa itsellenne.

## 4. Mooseksen kirja 31:19

Leiriytykää leirin ulkopuolelle seitsemäksi päiväksi; jokaisen, joka on tappanut ihmisen tai koskettanut kaatunutta, on puhdistauduttava kolmantena ja seitsemäntenä päivänä, sekä te että vangit.

## 4. Mooseksen kirja 31:20

Puhdistakaa jokainen vaate, jokainen nahkainen esine, kaikki vuohenkarvasta tehdyt ja jokainen puuesine."

## 4. Mooseksen kirja 31:21

Sitten pappi Eleasar sanoi sotilaille, jotka olivat olleet taistelussa: "Tämä on laki, jonka Herra on käskenyt Moosekselle:

## 4. Mooseksen kirja 31:22

Metallit, kuten kulta, hopea, pronssi, rauta, tina ja lyijy,

## 4. Mooseksen kirja 31:23

kaikki, mikä kestää tulta, on käytettävä tulen läpi, ja se on puhdas. Se on myös puhdistettava puhdistusvedellä. Mutta mikä ei kestä tulta, on käytettävä veden läpi.

## 4. Mooseksen kirja 31:24

Peseytykää seitsemäntenä päivänä, ja te olette puhtaat; sen jälkeen voitte tulla leiriin."

## 4. Mooseksen kirja 31:25

Herra puhui Moosekselle sanoen:

## 4. Mooseksen kirja 31:26

"Sinun ja pappi Eleasarin sekä seurakunnan isien perhekuntien päämiesten on laskettava saalis, joka on otettu, sekä ihmiset että karja;

## 4. Mooseksen kirja 31:27

ja jakakaa saalis sotilaille, jotka menivät taisteluun, ja muulle seurakunnalle.

## 4. Mooseksen kirja 31:28

Ottakaa Herralle annettavaksi sotaan menneiltä miehiltä yksi viidestäsadasta ihmisistä, karjasta, aaseista ja lampaista;

## 4. Mooseksen kirja 31:29

ottakaa se heidän osuudestaan ja antakaa se pappi Eleasarille Herran uhrilahjaksi.

## 4. Mooseksen kirja 31:30

Israelilaisten puolikkaasta ottakaa yksi viidestäkymmenestä ihmisistä, karjasta, aaseista, lampaista ja muista eläimistä, ja antakaa ne leeviläisille, jotka hoitavat Herran asumuksen tehtäviä."

## 4. Mooseksen kirja 31:31

Mooses ja pappi Eleasar tekivät, kuten Herra oli Moosekselle käskenyt.

## 4. Mooseksen kirja 31:32

Saalis, joka jäi sotilaiden ottamasta ryöstöstä, oli 675 000 lammasta,

## 4. Mooseksen kirja 31:33

ja seitsemänkymmentäkaksi tuhatta nautaa,

## 4. Mooseksen kirja 31:34

sekä kuusikymmentäyksi tuhatta aasia,

## 4. Mooseksen kirja 31:35

ja kolmekymmentäkaksi tuhatta naista, jotka eivät olleet maanneet miehen kanssa.

## 4. Mooseksen kirja 31:36

Sotaan menneiden puolikas oli: 337 500 lammasta,

## 4. Mooseksen kirja 31:37

joista Herran osuus oli 675;

## 4. Mooseksen kirja 31:38

kolmekymmentäkuusi tuhatta nautaa, joista Herran osuus oli 72;

## 4. Mooseksen kirja 31:39

kolmekymmentätuhatta viisisataa aasia, joista Herran osuus oli 61;

## 4. Mooseksen kirja 31:40

kuusitoista tuhatta ihmistä, joista Herran osuus oli 32.

## 4. Mooseksen kirja 31:41

Mooses antoi Herran uhrilahjan pappi Eleasarille, kuten Herra oli Moosekselle käskenyt.

## 4. Mooseksen kirja 31:42

Mitä tulee israelilaisten puolikkaaseen, jonka Mooses erotti sotaan menneiltä miehiltä—

## 4. Mooseksen kirja 31:43

seurakunnan puolikas oli 337 500 lammasta,

## 4. Mooseksen kirja 31:44

ja kolmekymmentäkuusi tuhatta nautaa,

## 4. Mooseksen kirja 31:45

sekä kolmekymmentätuhatta viisisataa aasia,

## 4. Mooseksen kirja 31:46

ja yhteensä kuusitoista tuhatta ihmistä.

## 4. Mooseksen kirja 31:47

Israelilaisten puolikkaasta Mooses otti yhden viidestäkymmenestä, sekä ihmisistä että eläimistä, ja antoi ne leeviläisille, jotka hoitavat Herran asumuksen tehtäviä, kuten Herra oli Moosekselle käskenyt.

## 4. Mooseksen kirja 31:48

Sitten armeijan yksiköiden päälliköt, tuhannen- ja sadanpäämiehet, lähestyivät Moosesta,

## 4. Mooseksen kirja 31:49

ja sanoivat hänelle: "Palvelijasi ovat laskeneet sotilaat, jotka ovat komennossamme, eikä ketään puutu.

## 4. Mooseksen kirja 31:50

Olemme tuoneet Herralle uhrilahjaksi, mitä kukin on löytänyt, kultaisia esineitä—rannekoruja, rannekkeita, sinettisormuksia, korvarenkaita ja kaulakoruja—sovittaaksemme itsemme Herran edessä."

## 4. Mooseksen kirja 31:51

Mooses ja pappi Eleasar ottivat heiltä vastaan kullan, kaikki taidokkaasti tehdyt esineet.

## 4. Mooseksen kirja 31:52

Kaikki kulta, jonka he toivat Herralle uhrilahjaksi, tuhannen- ja sadanpäämiehiltä, painoi 16 750 sekeliä.

## 4. Mooseksen kirja 31:53

Jokainen sotilas oli ottanut oman osuutensa ryöstöstä.

## 4. Mooseksen kirja 31:54

Mooses ja pappi Eleasar ottivat kullan tuhannen- ja sadanpäämiehiltä ja toivat sen ilmestysmajaan muistoksi israelilaisille Herran edessä.
