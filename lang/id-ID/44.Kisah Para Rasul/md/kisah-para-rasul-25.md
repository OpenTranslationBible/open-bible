# Kisah Para Rasul Pasal 25

## Kisah Para Rasul 25:1

Beberapa hari setelah tiba di provinsi itu, Festus pergi ke Yerusalem dari Kaisarea.

## Kisah Para Rasul 25:2

Imam-imam kepala dan para pemimpin orang Yahudi mengajukan tuduhan terhadap Paulus dan memohon kepada Festus.

## Kisah Para Rasul 25:3

Mereka meminta suatu kebaikan terhadap Paulus, agar dia dibawa ke Yerusalem, sementara mereka merencanakan penyergapan untuk membunuhnya di jalan.

## Kisah Para Rasul 25:4

Festus menjawab bahwa Paulus ditahan di Kaisarea, dan bahwa ia sendiri akan segera berangkat.

## Kisah Para Rasul 25:5

Ia berkata, "Biarlah orang-orang berpengaruh di antara kalian datang bersamaku, dan jika ada sesuatu yang salah tentang orang itu, biarlah mereka mengajukan tuduhan terhadapnya di sana."

---

## Kisah Para Rasul 25:6

Setelah menghabiskan delapan atau sepuluh hari dengan mereka, Festus pergi ke Kaisarea. Keesokan harinya, ia duduk di pengadilan dan memerintahkan Paulus dibawa ke hadapannya.

## Kisah Para Rasul 25:7

Ketika Paulus tiba, orang-orang Yahudi yang datang dari Yerusalem berdiri mengelilinginya, mengajukan banyak tuduhan serius yang tidak dapat mereka buktikan.

## Kisah Para Rasul 25:8

Paulus membela diri, menyatakan, "Saya tidak melakukan kesalahan apa pun terhadap hukum Yahudi, bait suci, atau Kaisar."

## Kisah Para Rasul 25:9

Festus, ingin menyenangkan orang-orang Yahudi, bertanya kepada Paulus, "Apakah kamu bersedia pergi ke Yerusalem dan diadili atas tuduhan ini di hadapanku?"

## Kisah Para Rasul 25:10

Paulus menjawab, "Saya berdiri di hadapan pengadilan Kaisar, tempat saya seharusnya diadili. Saya tidak bersalah terhadap orang Yahudi, seperti yang Anda ketahui dengan baik.

## Kisah Para Rasul 25:11

Jika saya bersalah dan telah melakukan sesuatu yang pantas dihukum mati, saya tidak menolak untuk mati; tetapi jika tuduhan terhadap saya tidak benar, tidak ada yang berhak menyerahkan saya kepada mereka. Saya naik banding kepada Kaisar!"

## Kisah Para Rasul 25:12

Setelah berunding dengan dewan, Festus menyatakan, "Kamu telah naik banding kepada Kaisar; kepada Kaisar kamu akan pergi."

---

## Kisah Para Rasul 25:13

Beberapa hari kemudian, Raja Agripa dan Bernike tiba di Kaisarea untuk memberi hormat kepada Festus.

## Kisah Para Rasul 25:14

Karena mereka menghabiskan banyak hari di sana, Festus membicarakan kasus Paulus dengan raja, mengatakan, "Ada seorang pria yang ditinggalkan sebagai tahanan oleh Feliks.

## Kisah Para Rasul 25:15

Ketika saya di Yerusalem, imam-imam kepala dan para tua-tua orang Yahudi mengajukan tuduhan terhadapnya, meminta hukuman mati.

## Kisah Para Rasul 25:16

Saya mengatakan kepada mereka bahwa bukan kebiasaan Romawi untuk menyerahkan siapa pun sebelum mereka menghadapi penuduh mereka dan memiliki kesempatan untuk membela diri terhadap tuduhan tersebut.

## Kisah Para Rasul 25:17

Ketika mereka datang ke sini bersama saya, saya tidak menunda, tetapi mengadakan sidang pengadilan keesokan harinya dan memerintahkan orang itu dibawa masuk.

## Kisah Para Rasul 25:18

Ketika para penuduhnya berdiri, mereka tidak menuduhnya dengan kejahatan yang saya harapkan.

## Kisah Para Rasul 25:19

Sebaliknya, mereka memiliki beberapa poin perselisihan dengannya tentang kepercayaan mereka sendiri dan tentang Yesus, yang telah mati dan yang Paulus tegaskan masih hidup.

## Kisah Para Rasul 25:20

Karena bingung tentang cara menyelidiki masalah semacam itu, saya bertanya apakah dia bersedia pergi ke Yerusalem dan diadili di sana.

## Kisah Para Rasul 25:21

Tetapi ketika Paulus naik banding untuk ditahan demi keputusan Kaisar, saya memerintahkan dia untuk tetap ditahan sampai saya dapat mengirimnya kepada Kaisar."

## Kisah Para Rasul 25:22

Agripa berkata kepada Festus, "Saya ingin mendengar orang itu sendiri." Festus menjawab, "Besok kamu akan mendengarnya."

---

## Kisah Para Rasul 25:23

Keesokan harinya, Agripa dan Bernike datang dengan kebesaran besar dan masuk ke ruang audiensi bersama dengan para perwira militer berpangkat tinggi dan orang-orang terkemuka kota. Atas perintah Festus, Paulus dibawa masuk.

## Kisah Para Rasul 25:24

Festus berkata, "Raja Agripa, dan semua yang hadir bersama kami, kamu melihat orang ini tentang siapa seluruh komunitas Yahudi telah mengajukan banding kepada saya, baik di Yerusalem maupun di sini, berteriak bahwa dia tidak seharusnya hidup lebih lama.

## Kisah Para Rasul 25:25

Saya menemukan dia tidak melakukan apa pun yang pantas dihukum mati, tetapi karena dia naik banding kepada Kaisar, saya memutuskan untuk mengirimnya ke Roma.

## Kisah Para Rasul 25:26

Namun, saya tidak memiliki sesuatu yang pasti untuk ditulis kepada Yang Mulia tentang dia. Oleh karena itu, saya membawanya ke hadapan kalian semua, dan terutama di hadapanmu, Raja Agripa, sehingga setelah penyelidikan ini, saya dapat memiliki sesuatu untuk ditulis.

## Kisah Para Rasul 25:27

Karena tampaknya tidak masuk akal bagi saya untuk mengirim seorang tahanan ke Roma tanpa menentukan tuduhan terhadapnya."
