# Yehezkiel Pasal 15

## Yehezkiel 15:1
Firman Tuhan datang kepadaku, mengatakan:

## Yehezkiel 15:2
“Anak manusia, apakah kayu dari pohon anggur lebih unggul dari cabang mana pun dari pohon-pohon di hutan?

## Yehezkiel 15:3
Dapatkah kayu diambil darinya untuk membuat sesuatu yang berguna? Dapatkah bahkan sebuah pasak dibuat darinya untuk menggantung barang apa pun?

## Yehezkiel 15:4
Jika itu dilemparkan ke dalam api untuk bahan bakar, dan api melahap kedua ujungnya dan membakar bagian tengahnya, apakah itu kemudian berguna untuk apa pun?

## Yehezkiel 15:5
Ketika itu utuh, itu tidak dibuat menjadi apa pun. Apalagi setelah itu dikonsumsi oleh api dan dibakar?

## Yehezkiel 15:6
Oleh karena itu, inilah yang dikatakan Tuhan Yang Berdaulat: Sama seperti kayu dari pohon anggur di antara pohon-pohon di hutan diberikan kepada api untuk bahan bakar, demikianlah Aku akan memperlakukan penduduk Yerusalem.

## Yehezkiel 15:7
Aku akan menentang mereka. Meskipun mereka telah keluar dari api, api akan tetap menghabisi mereka. Dan kamu akan tahu bahwa Akulah Tuhan ketika Aku menentang mereka.

## Yehezkiel 15:8
Aku akan membuat tanah itu tandus karena mereka telah bertindak tidak setia, demikianlah firman Tuhan Yang Berdaulat.”
