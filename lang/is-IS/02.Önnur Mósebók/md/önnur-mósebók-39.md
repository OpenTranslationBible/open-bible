# 2. Mósebók Kafli 39

## 2. Mósebók 39:1
Úr fjólubláum, purpura og skarlatsgarnum gerðu þeir fínofin klæði til þjónustu í helgidóminum, ásamt hinum helgu klæðum fyrir Aron, eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:2
Efódinn var gerður úr gulli, og úr fjólubláum, purpura og skarlatsgarnum, og fínofnum líni.

## 2. Mósebók 39:3
Þeir slógu gullplötur og skáru þær í þræði til að vefa í fjólubláa, purpura og skarlatsgarn, og fínofið lín, verk hagleiksmanna.

## 2. Mósebók 39:4
Þeir gerðu axlarstykki fyrir efódinn, sem voru fest við tvö efri horn hans.

## 2. Mósebók 39:5
Vefnaðurinn á belti efóðsins var af sama verki og efni: gull, fjólublátt, purpura og skarlatsgarn, og fínofið lín, eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:6
Þeir settu onyxsteina í gullfléttur, grafnir eins og innsigli með nöfnum Ísraels sona.

## 2. Mósebók 39:7
Þessir voru settir á axlarstykki efóðsins sem minningarsteinar fyrir Ísraels syni, eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:8
Brjóstskjöldurinn var gerður af hagleiksmanni, eins og efódinn, úr gulli, og úr fjólubláum, purpura og skarlatsgarnum, og fínofnu líni.

## 2. Mósebók 39:9
Hann var ferkantaður og tvöfaldur, spann á lengd og breidd.

## 2. Mósebók 39:10
Þeir settu fjórar raðir af gimsteinum á hann. Fyrsta röðin var rúbín, topas og smaragð;

## 2. Mósebók 39:11
önnur röðin var túrkís, safír og skýr steinn;

## 2. Mósebók 39:12
þriðja röðin var jaspis, agat og purpurasteinn;

## 2. Mósebók 39:13
fjórða röðin var beryl, onyx og jaspis. Þessir voru settir í gullfléttur.

## 2. Mósebók 39:14
Það voru tólf steinar, hver grafinn eins og innsigli með nafni eins af tólf ættkvíslum Ísraels.

## 2. Mósebók 39:15
Fyrir brjóstskjöldinn gerðu þeir keðjur úr skíru gulli, snúnar eins og bönd.

## 2. Mósebók 39:16
Þeir gerðu tvær gullfléttur og tvö gullhringi, og festu hringina á tvö horn brjóstskjaldarins.

## 2. Mósebók 39:17
Tvær gullkeðjurnar voru festar við hringina á hornum brjóstskjaldarins.

## 2. Mósebók 39:18
Hinir endar keðjanna voru festir við tvær fléttur, festar við axlarstykki efóðsins að framan.

## 2. Mósebók 39:19
Þeir gerðu tvo gullhringi og festu þá við hin tvö horn brjóstskjaldarins, á innri brún við hlið efóðsins.

## 2. Mósebók 39:20
Þeir gerðu einnig tvo fleiri gullhringi og festu þá við neðri hluta axlarstykki efóðsins, að framan, nálægt saumnum fyrir ofan beltið.

## 2. Mósebók 39:21
Hringir brjóstskjaldarins voru bundnir við hringi efóðsins með fjólubláu bandi, svo að brjóstskjöldurinn væri festur við beltið og sveiflaðist ekki út, eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:22
Kyrtill efóðsins var gerður alveg úr fjólubláu klæði, verk vefara.

## 2. Mósebók 39:23
Hann hafði op í miðjunni, eins og op brynju, með bandi um opið til að koma í veg fyrir rifur.

## 2. Mósebók 39:24
Þeir gerðu granatepli úr fjólubláum, purpura og skarlatsgarnum og fínofnu líni um fald kyrtilsins.

## 2. Mósebók 39:25
Hreinar gullbjöllur voru gerðar og settar á milli granateplanna um faldinn.

## 2. Mósebók 39:26
Bjöllurnar og granateplin skiptust á um fald kyrtilsins til þjónustu, eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:27
Kyrtlar úr fínofnu líni voru gerðir fyrir Aron og syni hans.

## 2. Mósebók 39:28
Þeir gerðu einnig túrban úr fínum líni, skreytta húfur og nærföt úr fínofnu líni.

## 2. Mósebók 39:29
Beltið var gert úr fínofnu líni og fjólubláu, purpura og skarlatsgarnum, verk útsaumsmanns, eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:30
Þeir gerðu plötuna, helga táknið, úr skíru gulli og grófu á hana, eins og áletrun á innsigli: "Helgað Drottni."

## 2. Mósebók 39:31
Fjólublátt band var fest við hana til að festa hana við túrbaninn, eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:32
Þannig var allt verkið við tjaldbúðina, samfundatjaldið, fullgert. Ísraelsmenn gerðu allt eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:33
Þeir færðu Móse tjaldbúðina: tjaldið og öll húsgögn þess, festingar, ramma, þverstöng, stólpa og undirstöður;

## 2. Mósebók 39:34
þak úr rauðlituðum hrútsskinnum, þak úr fínu leðri og varnarfortjaldið;

## 2. Mósebók 39:35
örkina með samningnum með stöngum sínum og friðþægingarlokið;

## 2. Mósebók 39:36
borðið með öllum áhöldum sínum og brauðinu sem var fyrir framan;

## 2. Mósebók 39:37
hreina gull ljósastandinn með lömpum sínum í röð og öllum fylgihlutum sínum, og ólífuolíuna fyrir ljósið;

## 2. Mósebók 39:38
gullaltarið, smurningarolíuna, ilmandi reykelsið og fortjaldið fyrir innganginn í tjaldið;

## 2. Mósebók 39:39
eiraltarið með eirgrindinni, stöngum sínum og öllum áhöldum sínum; skálina með stalli sínum;

## 2. Mósebók 39:40
fortjöld garðsins með stólpum sínum og undirstöðum, og fortjaldið fyrir innganginn í garðinn; reipin og tjaldhælana fyrir garðinn; öll áhöldin fyrir þjónustu tjaldbúðarinnar, samfundatjaldið;

## 2. Mósebók 39:41
og ofnu klæðin sem notuð voru til þjónustu í helgidóminum, bæði hin helgu klæði fyrir Aron prest og klæðin fyrir syni hans þegar þeir þjónuðu sem prestar.

## 2. Mósebók 39:42
Ísraelsmenn fullkomnuðu öll verkin nákvæmlega eins og Drottinn hafði fyrirskipað Móse.

## 2. Mósebók 39:43
Móse skoðaði verkið og sá að þeir höfðu gert það eins og Drottinn hafði fyrirskipað. Svo blessaði Móse þá.
