# 2. Mósebók Kafli 38

## 2. Mósebók 38:1
Altari brennifórnarinnar var smíðað úr akasíuviði, fimm álna langt, fimm álna breitt og þrjár álnir hátt, og myndaði ferhyrning.

## 2. Mósebók 38:2
Horn voru smíðuð á hverju af fjórum hornum þess, öll úr einu stykki með altarinu, og það var klætt með eir.

## 2. Mósebók 38:3
Öll áhöldin fyrir altarið voru gerð úr eir, þar á meðal pottar, skóflur, skálar, kjötkvíslir og eldpönnur.

## 2. Mósebók 38:4
Grind úr eirneti var gerð fyrir altarið, staðsett undir brún þess, sem náði hálfa leið upp altarið.

## 2. Mósebók 38:5
Fjórir hringir voru steyptir á fjórum hornum eirgrindarinnar til að halda stöngunum.

## 2. Mósebók 38:6
Stangirnar voru gerðar úr akasíuviði og klæddar með eir.

## 2. Mósebók 38:7
Stangirnar voru settar í hringina á hliðum altarisins til að bera það. Altarið var gert holt, smíðað með plötum.

## 2. Mósebók 38:8
Eirkerið og stallur þess voru gerð úr speglum kvennanna sem þjónuðu við inngang samfundatjaldsins.

## 2. Mósebók 38:9
Síðan var gert garðhús. Suðurhliðin hafði hengingar úr fínofnu líni, hundrað álna langar.

## 2. Mósebók 38:10
Þessi hlið hafði tuttugu súlur með tuttugu eirstöplum, og silfurkrókar og bönd á súlunum.

## 2. Mósebók 38:11
Norðurhliðin var einnig hundrað álna löng, með tuttugu súlum og tuttugu eirstöplum, og silfurkrókar og bönd á súlunum.

## 2. Mósebók 38:12
Vesturhliðin hafði hengingar fimmtíu álna breiðar, með tíu súlum og tíu stöplum, með silfurkrókum og böndum á súlunum.

## 2. Mósebók 38:13
Austurhliðin, sem sneri að sólarupprás, var fimmtíu álna breið.

## 2. Mósebók 38:14
Á annarri hlið inngangsins voru hengingar fimmtán álna langar, með þremur súlum og þremur stöplum.

## 2. Mósebók 38:15
Á sama hátt, á hinni hlið inngangsins, voru hengingar fimmtán álna langar, með þremur súlum og þremur stöplum.

## 2. Mósebók 38:16
Allar hengingar í kringum garðhúsið voru úr fínofnu líni.

## 2. Mósebók 38:17
Stöplar fyrir súlurnar voru úr eir, á meðan krókar og bönd á súlunum voru úr silfri, og toppar þeirra voru klæddir með silfri. Þannig höfðu allar súlur garðhússins silfurbönd.

## 2. Mósebók 38:18
Fortjaldið fyrir inngang garðhússins var gert af vefara, með bláum, purpura og skarlatsgarnum og fínofnu líni. Það var tuttugu álna langt og fimm álna hátt, samsvarandi hengingum garðhússins.

## 2. Mósebók 38:19
Það hafði fjórar súlur og fjóra eirstöpla. Krókar þeirra og bönd voru úr silfri, og toppar þeirra voru klæddir með silfri.

## 2. Mósebók 38:20
Allir hælar tjaldbúðarinnar og umhverfis garðhússins voru gerðir úr eir.

## 2. Mósebók 38:21
Þetta eru magntölur efna sem notuð voru fyrir tjaldbúðina, tjaldbúð vitnisburðarins, eins og skráð var af Levítunum undir stjórn Móse, samkvæmt fyrirmælum Íþamar, sonar Arons prests.

## 2. Mósebók 38:22
Besalel, sonur Úrí, sonar Húrs, af ættkvísl Júda, framkvæmdi allt sem Drottinn bauð Móse.

## 2. Mósebók 38:23
Með honum var Óhólíab, sonur Ahísamak, af ættkvísl Dan, útskurðarmeistari, hönnuður og fær útsaumari í bláu, purpura og skarlatsgarnum og fínu líni.

## 2. Mósebók 38:24
Heildarmagn gulls frá bylgjufórninni sem notað var fyrir allt verkið á helgidóminum var tuttugu og níu talentur og 730 siklar, samkvæmt helgidómssikli.

## 2. Mósebók 38:25
Silfrið sem safnað var frá manntali samfélagsins nam hundrað talentum og 1,775 siklum, samkvæmt helgidómssikli.

## 2. Mósebók 38:26
Þetta var beka á mann, það er, hálfur sikill, samkvæmt helgidómssikli, frá hverjum manni tuttugu ára eða eldri, alls 603,550 menn.

## 2. Mósebók 38:27
Hundrað talenturnar af silfri voru notaðar til að steypa stöplana fyrir helgidóminn og fortjaldið—hundrað stöplar úr hundrað talentum, ein talenta á stöpul.

## 2. Mósebók 38:28
1,775 siklarnir voru notaðir til að gera króka fyrir súlurnar, til að klæða toppa þeirra, og til að gera bönd fyrir þær.

## 2. Mósebók 38:29
Eirinn frá bylgjufórninni nam sjötíu talentum og 2,400 siklum.

## 2. Mósebók 38:30
Þessi eir var notaður til að gera stöplana fyrir inngang samfundatjaldsins, eiraltarið með eirgrindinni, og öll áhöld þess.

## 2. Mósebók 38:31
Það var einnig notað fyrir stöplana í kringum garðhúsið og inngang þess, og fyrir alla hæla tjaldbúðarinnar og umhverfis garðhúsið.
