# Числа, глава 28

## Числа 28:1

Господь сказал Моисею следующие слова:

## Числа 28:2

«Повели израильтянам и скажи им: "Будьте внимательны, чтобы приносить Мне Мои жертвы, Мои хлебные жертвы, сожигаемые в огне, как приятное благоухание для Меня, в назначенные времена".

## Числа 28:3

Скажи им: "Вот жертва, сожигаемая в огне, которую вы должны приносить Господу: два однолетних ягненка мужского пола без порока, как постоянное всесожжение каждый день.

## Числа 28:4

Приносите одного ягненка утром и другого вечером;

## Числа 28:5

вместе с хлебной жертвой из одной десятой эйфы лучшей муки, смешанной с четвертью гина чистого масла.

## Числа 28:6

Это постоянное всесожжение, установленное на горе Синай, как приятное благоухание, жертва, сожигаемая в огне Господу.

## Числа 28:7

Сопровождающая возлияние должна составлять четверть гина крепкого напитка для каждого ягненка. Вылейте возлияние Господу в святилище.

## Числа 28:8

Предложите второго ягненка вечером с той же хлебной жертвой и возлиянием, как утром, жертва, сожигаемая в огне, успокаивающее благоухание Господу.

## Числа 28:9

"В день субботы приносите жертву из двух однолетних ягнят мужского пола без порока, с двумя десятыми эйфы лучшей муки, смешанной с маслом, как хлебную жертву, и ее возлияние.

## Числа 28:10

Это всесожжение для каждой субботы, наряду с регулярным всесожжением и его возлиянием.

## Числа 28:11

"В начале каждого месяца приносите Господу всесожжение из двух молодых быков, одного барана и семи однолетних ягнят мужского пола, всех без порока.

## Числа 28:12

Для каждого быка должна быть хлебная жертва из трех десятых эйфы лучшей муки, смешанной с маслом; для барана — хлебная жертва из двух десятых эйфы лучшей муки, смешанной с маслом;

## Числа 28:13

и для каждого ягненка — хлебная жертва из одной десятой эйфы лучшей муки, смешанной с маслом. Это всесожжение, приятное благоухание, жертва, сожигаемая в огне Господу.

## Числа 28:14

С каждым быком должно быть возлияние из половины гина вина; с бараном — треть гина; и с каждым ягненком — четверть гина. Это ежемесячное всесожжение, которое должно совершаться при каждом новолунии в течение года.

## Числа 28:15

В дополнение к регулярному всесожжению с его возлиянием приносите одного козла мужского пола как жертву за грех Господу.

## Числа 28:16

"Пасха Господня должна праздноваться в четырнадцатый день первого месяца.

## Числа 28:17

В пятнадцатый день этого месяца должен быть праздник; в течение семи дней ешьте пресный хлеб.

## Числа 28:18

В первый день проведите священное собрание и не делайте никакой тяжелой работы.

## Числа 28:19

Приносите Господу жертву, сожигаемую в огне, всесожжение из двух молодых быков, одного барана и семи однолетних ягнят мужского пола, всех без порока.

## Числа 28:20

Для каждого быка приготовьте хлебную жертву из трех десятых эйфы лучшей муки, смешанной с маслом; для барана — две десятых;

## Числа 28:21

и для каждого из семи ягнят — одну десятую.

## Числа 28:22

Приносите одного козла мужского пола как жертву за грех, чтобы обеспечить искупление для вас.

## Числа 28:23

Приносите эти жертвы в дополнение к регулярному утреннему всесожжению.

## Числа 28:24

Таким образом приносите хлебную жертву каждый день в течение семи дней как приятное благоухание Господу; она должна быть принесена в дополнение к регулярному всесожжению и его возлиянию.

## Числа 28:25

В седьмой день проведите священное собрание и не делайте никакой тяжелой работы.

## Числа 28:26

"В день первых плодов, когда вы приносите Господу жертву из нового зерна во время Праздника недель, проведите священное собрание и не делайте никакой тяжелой работы.

## Числа 28:27

Приносите всесожжение из двух молодых быков, одного барана и семи однолетних ягнят мужского пола как приятное благоухание Господу.

## Числа 28:28

Для каждого быка должна быть хлебная жертва из трех десятых эйфы лучшей муки, смешанной с маслом; для барана — две десятых;

## Числа 28:29

и для каждого из семи ягнят — одну десятую.

## Числа 28:30

Приносите одного козла мужского пола, чтобы обеспечить искупление для вас.

## Числа 28:31

Приносите их вместе с их возлияниями, в дополнение к регулярному всесожжению и его хлебной жертве. Убедитесь, что животные без порока.
